# L1–L4 数据质量门禁

| 层 | 必检项 | 证据 |
| --- | --- | --- |
| L1 结构 | 表、指标依赖列、类型、单位与实际粒度是否存在且一致 | schema 与必要样本 |
| L2 新鲜度 | 最新业务时间、期望延迟、请求时间范围是否有覆盖 | MIN / MAX 与范围统计 |
| L3 完整性 | 主键、时间列、度量与分母缺失，过滤前后覆盖 | COUNT 与条件聚合 |
| L4 唯一性 | 去重键重复、表粒度、关联扇出及聚合是否闭合 | DISTINCT、重复组与 join 核验 |

合并必要检查到发现 SQL，优先聚合，规划轮总计不超过八次查询。
不执行 DDL、修复写入或无关全库审计。

关键列不存在、定义无法执行、分母无效或无法解释的关联放大属于 `BLOCKED`；
排除受阻指标，交付可用部分。若全部关键指标受阻，停止建盘。
可限定影响范围的迟到、缺失或尚未确认的口径属于 `READY_WITH_CAVEATS`；
披露 caveat，不将其自动视为 READY。全部必检项通过才写 `READY`。
未执行的检查写“未检查”，不能声称质量门禁通过。
历史样例按实际覆盖日期披露；不把历史样例包装成实时业务数据。
