# 连接与指标口径检查

1. 从会话所选数据库或已注册上传数据集确认真实数据源及可见 schema。
   未选源先要求选择；连接失败和无权限说明真实原因。
2. 使用注入的元数据与已发布语义上下文。规划执行器仅提供有界看板工具，
   不凭空调用 ListCatalogs、SearchKnowledgeBase 或不存在的 MCP Server Key。
3. 检查表、列、样本日期格式、实际日期范围、单位和字段业务说明。
   使用真实数据库方言，文本日期根据样本解析并保留完整年份。
4. 为每个指标记录数据源、分子 / 分母、过滤、去重、时间归属、单位、基线，
   以及实际可用的定义来源与版本。语义定义未确认时展示拟采用口径和 caveat。
5. 多文件源检查来源清单与关联基数；多 Provider 暂不合并为一个原生看板。
   已选源可用就继续可用部分，不假装连接或检索了另一数据源。

错误处理：权限拒绝不反复重试；缺列 / 方言错误依据真实反馈修正一次；
超时先调整扫描范围或聚合方式，不重复原查询；发现预算耗尽时交付已确认
的规划范围，说明尚未覆盖的视图和继续成本。
