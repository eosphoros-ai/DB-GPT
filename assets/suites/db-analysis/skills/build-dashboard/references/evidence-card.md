# 数据证据卡

最终交付必须包含以下十项，允许在原生规划 / 草稿的业务说明及消息中呈现：

1. 决策用途与受众。
2. 实际使用的数据源展示名和可见表范围。
3. 绝对时间范围、时间粒度与数据截止时间。
4. 指标定义及版本或“未经语义中心确认”标记。
5. 分子、分母、过滤、去重键、时间归属和单位。
6. 真实执行 SQL / 执行记录与对应组件，保留可复算的依据。
7. 数据质量 L1–L4 结果、就绪等级与 caveat / 阻断原因。
8. 对比基线、计算方式与目标来源；未提供的目标不编造。
9. 筛选范围、实际刷新方式及空状态 / 错误状态。
10. 覆盖限制、缺失视图和待人工复核的高影响结论。

关键数字必须由同范围真实 SQL 支撑，禁止从有限样本外推全集。
触及 LIMIT 时先按所需粒度在引擎中聚合，必要时补同过滤范围 COUNT。
Success=false、超时或权限拒绝是失败，不是无数据，更不是指标值 0。
无数据范围不更换日期或伪造一行数据；原生空表计划保留真实过滤条件。
复杂度决定篇幅，简单请求不套完整大报告；完整证据字段可简短呈现。
