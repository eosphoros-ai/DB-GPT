# 法律专家套件

面向企业内部法务、执业律师与法务支持岗位的法律工作助手。它把散落的事实、合同和往来材料，整理成有出处、可复核、可流转的法务工作底稿与法律文书初稿。

## 这个套件解决什么问题

法务工作的常见失效点通常不是“不会写”，而是：事实没理顺就下结论、法条靠记忆引用导致条号出错、合同审查只挑措辞不看立场和商业目的、争议评估只给结论不给路径对比、文书缺要件被退回或无法签发。

本套件按「先事实、再依据、后结论、最后成文」的顺序拆成五个技能，每个技能都写清了输入要求、执行步骤、产物格式、质量检查和失败处理。

## 技能清单

| 技能 | 命令 | 作用 |
| --- | --- | --- |
| legal-intake | /案情梳理 | 受理需求，抽出主体、时间线、事实分层、争点与缺失信息 |
| legal-research | /法规检索 | 检索并核验法律法规与案例，输出带来源 URL 的依据表 |
| contract-review | /合同审查 | 按委托立场逐条审查合同，输出分级风险清单与替换文本 |
| dispute-strategy | /争议评估 | 请求权基础、时效与管辖核查、多路径对比与升级判断 |
| legal-drafting | /文书起草 | 起草律师函、法律意见书、起诉状要点等文书骨架 |

## 典型用法

- 「帮我审一下这份采购合同，我方是买方，重点看付款、验收和违约条款。」
- 「对方拖欠货款 8 个月，现在只肯口头承诺，帮我比较协商、仲裁、起诉三者的成本和时间。」
- 「根据这些聊天记录和送货单，起草一封催款律师函。」
- 「《民法典》里违约金调整现在是怎么规定的？给我条文原文和来源。」
- 「员工离职带走客户名单，我们能不能主张侵犯商业秘密？」

## 使用边界（重要）

- 本套件输出的是**工作底稿与文书初稿**，不构成正式法律意见，不能直接对外签发。
- 所有法条与案例引用都必须附来源链接；未核验的内容会明确标注「未核验」，不会伪造条号或案号。
- 涉及刑事风险、行政处罚、证券与反垄断合规、数据出境、跨境制裁、劳动群体争议等情形时，套件会停止自动推进并提示转人工。
- 当事人名称、金额、期限等未知信息一律以 [[待补充]] 占位，不允许自行编造。

## 安装后配置

- 不依赖数据库，安装后即可使用。
- 建议开启联网检索能力（web_search / web_fetch）用于法条与案例核验；若环境不可用，技能会降级为「结构输出 + 待核验标记」，不会凭记忆给条号。
- 建议把企业内部合同模板、审查要点清单、历史争议案例贴在会话材料中，审查质量会明显提升。
