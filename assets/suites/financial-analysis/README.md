# 财报分析

上传年度报告 PDF，阅读有原文依据的财务分析，或比较多家公司、多个报告年度。无需连接数据库。

## 快捷命令

| 命令 | 材料 | 用途 |
| --- | --- | --- |
| `/读年报` | 一份 PDF 年报 | 分析经营表现、扣非与利润构成、毛利、费用、现金流、资产负债 |
| `/财报对比` | 两到五份 PDF 年报 | 比较同一报告年度的不同公司，或同一公司的不同报告年度 |

在首页或会话输入框输入 `/` 选择任务，上传材料并说明关注的问题。也可以从本页点击快捷命令开始。已经生成报告后，可在原会话继续追问，无需重复上传和提取。

## 报告与证据

分析通过专用财报工具提取数据、计算指标、逐专题分析和复核，在会话中展示报告。数字引用关联原文页码和计算依据。部分专题失败或资料不足时保留已验证的结果，并说明具体缺口；仅已发布的报告显示为完成。

## 当前支持范围

支持具有文本层的中文、人民币、非金融企业年度报告 PDF。扫描件、自动 OCR、季度报告、跨币种换算及金融企业专用报表口径暂不支持。自动提取与模型复核不等于人工核验。

比较前请明确是同年多公司还是同公司跨年；公司身份、报告年度或比较基准不清楚时，需要先确认。文件数量本身不代表比较意图。
