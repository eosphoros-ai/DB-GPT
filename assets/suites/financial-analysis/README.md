# 财报分析

上传年度报告 PDF，阅读有原文依据的财务分析，或比较多家公司、多个报告年度。无需连接数据库。

## 快捷命令

| 命令 | 材料 | 用途 |
| --- | --- | --- |
| `/读年报` | 一份 PDF 年报 | 分析经营表现、扣非与利润构成、毛利、费用、现金流、资产负债 |
| `/财报对比` | 两到五份 PDF 年报 | 比较同一报告年度的不同公司，或同一公司的不同报告年度 |
| `/查股票` | 股票名称、代码、行业或概念 | 查询沪深 A 股和港股个股，或查看 A 股板块指数涨跌、涨跌家数和领涨领跌个股 |

在首页或会话输入框输入 `/` 选择任务，也可以从本页点击快捷命令开始。年报任务需要上传报告并说明关注的问题。已经生成报告后，可在原会话继续追问，无需重复上传和提取。

可以直接提问，也可以点击“查股票”编辑默认问题。Agent 根据整句和上下文决定是否需要行情。例如，“时间会证明光模块吗？”会围绕长期判断作答。“先查今天光模块的走势，再说这能否说明长期需求”会先取行情，再解释这组数据能支持什么判断。

行情查询无需附件、业务数据库或行情 API Key。“腾讯现在多少钱”返回行情源的最新报价和更新时间。“腾讯今天收盘价是多少”才查港交所日报，日报尚未发布时显示收盘价待确认。沪深股票的收盘价通过相应交易所核对。“刚才的成交额呢”直接读取原轮快照。

例如，输入“今天光模块咋样”可查看东方财富“光通信模块”板块。输入“科技股怎么样”后，可以回复“半导体”或序号选择方向。板块整体涨跌取自板块指数，领涨、领跌按同一板块成分股当日涨跌幅分别列出最多三只。“刚才谁领跌”会读取刚才的排名。

## 报告与证据

分析通过专用财报工具提取数据、计算指标、逐专题分析和复核，在会话中展示报告。数字引用关联原文页码和计算依据。部分专题失败或资料不足时保留已验证的结果，并说明具体缺口；仅已发布的报告显示为完成。

## 当前支持范围

支持具有文本层的中文、人民币、非金融企业年度报告 PDF。扫描件、自动 OCR、季度报告、跨币种换算及金融企业专用报表口径暂不支持。自动提取与模型复核不等于人工核验。

比较前请明确是同年多公司还是同公司跨年；公司身份、报告年度或比较基准不清楚时，需要先确认。文件数量本身不代表比较意图。
