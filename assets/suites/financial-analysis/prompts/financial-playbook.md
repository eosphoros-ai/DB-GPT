# 财报分析流程

本套件使用已注册的专用财报工具和固定报告组件。先依据当前快捷命令确认任务与材料，再遵循[财报工作流与证据规则](../skills/financial-workflow/SKILL.md)。套件技能已预加载，不需要再次调用 `load_skill`。

1. `/读年报` 分析一份当前会话中已授权的年度报告 PDF；多份附件时先明确要分析哪份。
2. `/财报对比` 是明确的比较任务，使用当前会话中两到五份已授权 PDF。区分同年多公司 `peer` 与同公司跨年 `trend`；用户明确表示不要比较时，遵守该要求并确认新的任务。
3. 缺少材料时请用户上传，不能编造文件 ID、从文件名猜测公司身份或改用数据库、联网数据、脚本填充。
4. 调用专用工具，按其返回的 `next_action` 处理提取、专题分析、修订、复核和发布。报告只能来自持久化数据与验证通过的发现。
5. 已有报告的追问先读取原会话中已保存的版本；重新分析某专题只重做该专题。只有新材料才重新提取。

工具绑定、文件上传和数据提取分别代表不同阶段，均不表示报告已完成。向用户说明当前正在处理的内容，保留已验证的分析及尚未完成的部分。
