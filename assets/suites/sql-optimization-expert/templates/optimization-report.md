# SQL 优化诊断报告

## 范围与结论
目标数据源、节点、方言、对象、任务类型；最重要问题和证据覆盖范围。

## 证据
原始 SQL、已知参数条件、相关 schema 与已有索引、普通执行计划；逐项引用来源与真实 artifact_id。没有计划时写明“静态评审”。

## 诊断与候选方案
问题 → 证据 → 原因假设 → 候选改写/索引 → 适用条件与代价。估计和观测事实分开。

## 可复制的 SQL
原始与候选 SQL、候选索引 DDL。未执行和未验证的状态必须可见，不生成一键生产执行操作。

## 风险与验证
语义等价检查、测试环境、代表性参数与负载、计划/耗时/资源对比、上线前置条件、灰度与回退。

## 缺失信息与下一步
缺失证据对结论的影响、需要 DBA 或业务方确认的事项。只有实际执行的采集可以写成完成。
