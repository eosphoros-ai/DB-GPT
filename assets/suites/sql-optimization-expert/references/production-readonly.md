# 生产读取规则

- 仅使用绑定的数据源和授权对象。没有权限时停止该项采集，不能换账号、调用 shell 或绕过工具。
- 默认读取 schema、索引和普通执行计划。不执行原始业务查询做耗时对比，不为采集信息执行 ANALYZE、DDL、参数修改或统计重置。
- 普通 EXPLAIN 也可能消耗规划资源或触发数据库特定行为；遇到昂贵规划、特殊函数或兼容性不明时，使用用户提供的计划。
- EXPLAIN ANALYZE 会实际执行语句，本版本禁止。拒绝 FOR UPDATE、FOR SHARE、锁函数、延迟函数和未知副作用函数。
- 限定 schema/table，优先小范围系统目录查询；业务数据采样需要用户明确范围和部署侧许可。不要执行全表 COUNT、无界聚合或随机排序采样。
- 工具超时不等于数据库端已取消；发生超时停止原样重试，注明终止状态未确认，并交给 DBA 检查。
- 相同采集连续失败两次即停止，继续使用已获得证据完成可交付部分。
- 不将密码、凭据、个人数据或未经许可的 SQL 字面量写入报告。引用证据时保留来源、时点和对象范围。
- 索引和 DDL 只输出建议。不得将反向 DDL 当作可靠回滚；破坏性修改需要备份、恢复演练或经过验证的数据恢复路径。
