# Connectors

本套件按**品类**引用外部工具：技能里写的是"文档平台""任务工具"，不是某个具体产品。同一品类连上任意一个工具即可，套件不依赖任何连接器——**没有连接器时所有技能均可正常使用**（你贴诊断输出，我出结论）。

## 品类与增强能力

| 品类 | 连上后能做什么 | 支持的工具 | 配置方式 | 被哪些技能使用 |
|:---|:---|:---|:---|:---|
| **数据库**（MySQL 只读） | 直接执行 `EXPLAIN`、`SHOW GLOBAL STATUS`、`information_schema` 查询并解析结果；支持多实例批量巡检，无需人工粘贴 | 自建 MySQL 的 MCP Server、云厂商数据库助手 | 需你本地接入（见下方"接入方式"） | SQL 体检、实例巡检、参数调优、变更评审、备份恢复 |
| **监控指标** | 拉取 7/30 天曲线做环比与增长斜率计算，容量报告自动给出触顶日期；故障时自动对齐变更时间线 | Prometheus、Grafana、Zabbix、云监控 API | 需你本地接入 | 实例巡检、故障应急、运维报告 |
| **文档平台** | 报告与变更方案自动发布为文档并归档，形成可追溯历史序列 | 钉钉文档、飞书文档、语雀、Notion、Confluence | 钉钉/飞书：内置连接器，设置里开启；语雀/Notion/Confluence：需自行接入 | 全部技能 |
| **任务工具** | 问题清单批量建待办并指派、超期提醒；上期承诺状态自动回填本期报告；临时措施登记为"待回退"任务 | 钉钉待办、飞书任务、Linear、Jira、禅道 | 钉钉：内置；其余需自行接入 | 实例巡检、SQL 体检、变更评审、运维报告 |
| **沟通工具** | 把"当前判定 + 止血动作 + 待确认项"推送到应急群；报告摘要按节奏播报 | 钉钉、飞书、企业微信、Slack | 钉钉：内置（当前已安装）；飞书/企业微信：内置，需登录授权 | 故障应急、运维报告 |
| **知识库** | 与巡检记录、复盘文档互相引用，形成单一事实来源 | 钉钉知识库、飞书知识库、Confluence | 钉钉：内置 | 运维报告、实例巡检 |
| **变更管理** | 需重启的参数与 DDL 自动挂变更单，生成评审方案骨架 | Jira、禅道、云工单 | 需自行接入 | 变更评审、参数调优 |

## 内置连接器（无需配置 MCP）

**钉钉**、**飞书**、**企业微信** 属于当前应用内置支持的连接器：在 **设置 → Connector** 里开启并授权登录即可，不需要填任何配置页、也不需要粘贴 JSON。开启后，本套件的文档平台 / 任务工具 / 沟通工具 / 知识库四个品类会自动使用它们。

## 数据库与监控类连接的接入方式

这两类通常是**你本地自建的 MCP Server**（例如 MySQL 只读 MCP、Prometheus MCP），配置里包含你的主机、端口与账号，属于个人环境信息，因此**不随插件分发**，也不写入 `.mcp.json`。

推荐做法：

1. 在当前应用的 **设置 → Connector → 自定义 MCP** 中添加你的 MySQL / Prometheus MCP Server（**数据库账号请使用只读账号**，权限建议 `SELECT` + `REPLICATION CLIENT` + `PROCESS`，不要给 `SUPER`/`ALL PRIVILEGES`）。
2. 接入后无需改动本套件任何文件——技能按品类识别，会自动使用已连接的工具。
3. 若你希望插件自带"配置引导"（安装后在插件详情页直接填配置），把你的 MCP 配置页地址告诉助手，即可补一份 `.mcp.json` 的 `guided-setup` 声明。

> 只读原则：即使连了数据库，本套件的**写操作类命令（L2/L3）也一律只输出方案与命令，不代为执行**。变更与恢复仍需人工在有权限的通道上确认执行。

## 无连接器时的使用方式（默认路径）

| 需要的数据 | 自己采集的命令 | 贴回来即可 |
|:---|:---|:---|
| 实例基础与指标 | `SHOW GLOBAL VARIABLES`；间隔 60s 两次 `SHOW GLOBAL STATUS`；`SHOW ENGINE INNODB STATUS\G` | ✅ |
| 会话与锁 | `SHOW FULL PROCESSLIST`；`SELECT * FROM information_schema.innodb_trx` | ✅ |
| SQL 诊断 | `SHOW CREATE TABLE`、`SHOW INDEX FROM`、`EXPLAIN FORMAT=TREE` | ✅ |
| 巡检采集 | `@实例巡检` 说"给我采集脚本"，得到一份可直接跑的 `patrol.sh` | ✅ |
| 容量趋势 | 云监控/`iostat`/`df` 导出 CSV 或截图 | ✅ |
| 备份现状 | `SHOW BINARY LOGS`、备份目录列表、云备份页截图 | ✅ |

所有技能在没有连接器的情况下均可完整使用；采集不到的项会在报告中显式列入"待采集"，不会用估算值替代。
