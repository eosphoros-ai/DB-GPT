# 安全红线与执行分级

**套件的强制自检文件**：任何技能在输出可执行命令、参数建议、变更方案之前，都必须按本文件分级并标注。

## 命令分级（输出时必须打标）

| 级别 | 定义 | 示例 | 输出要求 |
|:---|:---|:---|:---|
| 🟢 **L0 只读** | 不修改任何状态，可任意时点执行 | `SHOW`、`SELECT` 查 I_S/P_S、`EXPLAIN FORMAT=TREE`、`df`/`iostat` | 直接给 |
| 🟡 **L1 低风险可回退** | 改内存态/可即时改回，影响面可控 | `SET GLOBAL` 动态参数（有上限保护时）、`FLUSH SLOW LOGS`、`ANALYZE TABLE`（轻量表）、`KILL` 只读 SELECT | 给出**当前值 + 新值 + 回退命令 + 观察指标** |
| 🟠 **L2 需审批** | 有锁/IO/空间开销，或作用于写路径 | `KILL` 有未提交事务的连接、`OPTIMIZE TABLE`、`PURGE BINARY LOGS`、大表 `ANALYZE`、加索引、批量 `DELETE`、改 `max_connections` | 必须先说明**影响窗口、预估耗时、回滚方案**，并在方案中要求人工确认 |
| 🔴 **L3 高危/最后手段** | 可能造成数据丢失、不一致或实例不可用 | `innodb_force_recovery`、`RESET MASTER`、`sql_replica_skip_counter`、删表空间文件、`--skip-grant-tables`、从库改 `read_only=OFF`、直接改物理文件 | 默认**不主动建议**；仅在用户明确授权且已做物理备份时给出，且必须写出"不可逆点"在哪一步 |

打标格式：在每条命令同行末尾或上方用 `-- [L1]` / **L2 需审批** 标注，并在方案末尾汇总"L2/L3 操作清单"。

## 六条硬红线

1. **不猜数据**。任何结论涉及的数值必须有来源（用户贴出的输出 / 待采集命令）。缺失就写"待采集：`<命令>`"，禁止用估算值、示例值冒充实测值。
2. **不默认改参数**。所有 `SET GLOBAL` 必须：说明为什么、当前值、目标值、是否持久化（`SET PERSIST` vs 改配置文件）、重启后行为、回退命令。参数变更一律建议先在**从库/灰度实例**验证。
3. **不在主库做重活**。大表扫描、`EXPLAIN ANALYZE`（会真执行）、备份、`pt-table-checksum`、归档 `DELETE` 优先安排从库或低峰；无法确认拓扑时先问。
4. **不做无备份的恢复动作**。任何 PITR、表重建、数据订正前，先确认最近一次全备时间 + binlog 覆盖区间；不满足就明确写"恢复点不覆盖，需先补全备"。
5. **不删文件**。清理磁盘只走 SQL/`PURGE`/日志轮转（`FLUSH ERROR LOGS`、`mysqladmin flush-logs`）路径，绝不建议 `rm` 数据目录、binlog、undo、`#sql-*` 中间文件。
6. **不输出敏感数据**。示例 SQL 与报告中的库表名、账号、IP、连接串、业务字段值需脱敏为 `<db>`、`<tbl>`、`10.x.x.x`、`app_user`；用户贴出的含真实数据行**不复述明文**，只描述结构与统计特征。

## 云上环境附加约束

- 云 RDS 多数无 `SUPER`：`KILL` 只能杀自己权限内的会话；`SET GLOBAL` 需通过控制台参数模板下发（区分**立即生效**与**需重启**）。
- 磁盘到达规格上限会被**锁定为只读**，此时任何写入失败都是环境导致，不是 SQL 问题。
- `performance_schema` 部分 consumer/instrument 默认关闭，取不到数时先给"如何确认已开启"的命令，而不是换结论。
- 主从切换由平台 HA 触发，人工介入前先看控制台事件，避免与平台动作打架。

## 变更方案必备要素（缺一不合规）

动机与影响面 → 执行窗口 → 前置检查 → 具体步骤（分步可中断）→ 进度观测点 → **回滚方案与回滚耗时** → 验证方法 → 应急联系人 → 失败后的数据处理。

**没有回滚方案的变更不允许出现在输出里。** 无法回滚的（如 `DROP COLUMN`、字段类型收窄），必须显式写"不可逆"并给出补偿（影子表保留原字段、双写期、备份恢复演练验证过）。

## 输出可信度声明

每份诊断/方案末尾附一行：

> 本次结论基于 <数据来源与时间范围>；未覆盖的验证项：<列表>。建议在执行前人工复核 L2/L3 操作。

## 应急场景的例外规则

在故障应急（P0/P1）语境下，**止血优先于完美**：允许给出 L2 操作并明确标注"应急临时措施，恢复后必须回退到基线配置"，同时给出回退命令。但仍受红线 1、5、6 约束。
