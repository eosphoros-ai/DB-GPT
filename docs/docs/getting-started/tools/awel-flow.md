# AWEL Flow (retired)

The visual AWEL flow editor docs have been retired. Workflows are now the product surface for
building reusable pipelines: a declared node chain of scoped agents that runs from chat, with
first-class artifacts and confirmation gates. AWEL remains the compile target underneath.
