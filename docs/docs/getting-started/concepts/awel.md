# AWEL (retired)

AWEL (Agentic Workflow Expression Language) concept docs have been retired. The product surface
for workflows is now the TaskFlow node chain — see [What is a Workflow](/docs/workflow/introduction).
AWEL remains the DAG layer that flows compile to; operator-level extension is covered in
[Custom operators](/docs/workflow/custom-operator).
