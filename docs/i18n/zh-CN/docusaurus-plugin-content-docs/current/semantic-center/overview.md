# 语义中心

语义中心连接数据库物理结构与业务含义，让团队审核定义、发布指标版本，并让 Data Agent 读取和引用这些依据。

例如“1 月净实收”不只是一个 `SUM`：是否含运费，哪些订单有效，2 月退款是否影响 1 月？将这些约定记录并审核，可以减少跨查询和报告的重复解释。

![已登记的语义数据空间](/img/data-agent/zh-CN/semantic-spaces.png)

| 对象 | 用途 |
| --- | --- |
| 数据空间 | 与已登记数据库连接关联的语义记录 |
| 元数据 | 同步的表字段、类型、注释、键和维护标签 |
| 业务语义 | 审核后的表字段含义与同义词 |
| 指标 | 有业务范围与计算定义的命名指标 |
| 已发布指标版本 | 可按精确版本读取并引用的快照 |
| 样例、关系、护栏 | 可维护的辅助上下文；运行时消费程度不同 |

数据库提供物理事实，语义中心管理业务解释，知识库存放检索资料，插件提供任务方法。知识库检索不替代已发布指标定义。

## Agent 当前读取什么

数据库绑定的只读工具提供元数据、已发布业务定义、指标搜索与精确版本读取。搜索使用关键词与已保存别名；草稿不作为已发布指标返回，请求版本缺失时不自动换版本。

界面也提供样例、关系与护栏，但界面存在不等于当前工具已消费或强制执行这些规则。元数据是快照，结构变更后应重新同步。
