# 语义中心排查

| 现象 | 检查与处理 |
| --- | --- |
| 数据空间没有连接 | 先在数据源验证连接，再登记并检查逐连接错误 |
| 空间未激活 | 检查激活选项；元数据可在未激活时读取，但草稿不会因此发布 |
| 指标搜索为空 | 核对数据库、发布版本、名称和别名；用较短业务词搜索 |
| 业务定义缺失 | 确认已发布，且目标表字段仍存在 |
| 指定版本不存在 | 检查版本记录并解决需要的版本；不会自动回退 |
| 字段与库不一致 | 结构变更后同步元数据并审核受影响定义 |
| 没有语义工具 | 确认数据库加载成功，当前 Agent 路径支持挂载 |
| 护栏未限制 SQL | 界面记录不等于执行强制；检查数据库权限与实际工具配置 |

## 提交可定位的问题

提供插件、无凭据的连接名称、指标名称/ID/版本、空间与发布状态、搜索词、错误及相关工具结果，去除敏感数据。

不要为了消除空结果而发布未审核草稿。缺失定义应先澄清，再计算。
