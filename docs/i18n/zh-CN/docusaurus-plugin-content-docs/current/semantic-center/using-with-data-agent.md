# 与 Data Agent 配合

选择语义空间所属数据库。连接加载成功后，智能取数和智能分析的相应执行路径挂载语义只读工具，无需另外绑定普通知识库。

```text
查询2026年1月净实收并按获客来源拆分。
先读取已发布净实收口径与版本，再读取到账日期和获客来源的业务定义，
核对实际字段，遵循支付、退款时间规则，避免商品、支付和退款关联放大。
输出已执行 SQL、金额（元）、指标引用和缺失定义。
```

使用 `Semantic_Commerce_Case` 时，在首页选择“语义中心：净实收取数”。这是模拟演示，真实任务应使用自己的已审核指标。

![智能取数推荐问题](/img/data-agent/zh-CN/query-entry.png)

| 工具 | 返回内容 |
| --- | --- |
| `semantic_search_metrics` | 关键词或别名匹配的已发布指标 |
| `semantic_get_metric` | 按 ID/名称与可选精确版本读取完整快照 |
| `semantic_search_business` | 已发布的表字段业务含义和别名 |
| `semantic_get_metadata` | 表字段快照与维护标签 |

长问题未命中时分别检索业务名词，必要时缩小表范围。结果包含空间、来源与截断信息。工具绑定当前连接，模型不能用参数切换到其他数据库。

## 核验引用与 SQL

逐项比较快照与 SQL 的单位、时间、过滤和粒度，查看实际执行结果及行数限制。引用标识定义来源，不认证 SQL 已实现全部规则。

涉及血缘时，区分指标依赖、声明外键和推断关系。这四个工具不提供通用调度任务或端到端血缘发现。
