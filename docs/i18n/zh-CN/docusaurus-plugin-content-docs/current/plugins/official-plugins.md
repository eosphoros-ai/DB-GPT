# 官方插件

首页聚焦以下五个官方场景，是否可用取决于启用状态和资源配置。

| 插件 | 输入 | 典型交付 | 首次问题 |
| --- | --- | --- | --- |
| 智能取数 | 数据库；涉及口径时提供已发布定义 | SQL、结果表与可用指标引用 | 按来源查询净实收 |
| 智能分析 | 数据库或合适文件、期间与目标 | 分析、报告、看板 | Walmart 销售看板 |
| SQL 优化专家 | 数据库、SQL、参数与症状 | 诊断、改写/索引候选与验证计划 | 诊断 SQL 瓶颈 |
| 元数据与架构专家 | 数据库与表范围 | 字典、物理 ER、结构报告 | 指定表数据字典 |
| 财报分析 | 财报文件与期间 | 带来源的财务分析和报告 | 解读上传年报 |

## 智能取数

从范围明确的问题开始，先读取已发布指标，再核对时间、过滤与 JOIN。电商推荐问题覆盖净实收、运费、关联放大和跨月归属，使用模拟数据。

## 智能分析

说明报告支持什么决策。制作看板时先确认规划，生成后打开组件，核对时间轴、单位和数据。SQL 可执行不等于组件正确。

## SQL 优化专家

提供真实 SQL 和引擎，区分实测、计划估计与静态推断。默认诊断不执行 DDL 或 `EXPLAIN ANALYZE`，索引候选和改写需要语义及负载验证。

## 元数据与架构专家

限定对象范围，以目录查询为物理事实依据。缺失注释应保持未知，声明外键与推断关联分开；推断不能转为真实约束或 DBML 外键。

## 财报分析

提供可追溯文件、期间、货币和单位，检查引用与会计可比性。文件不完整时缩小任务，不补造数字。
