# 使用插件

## 查找与检查

从侧栏**专家套件**进入插件中心，浏览官方、企业与已安装视图，或搜索名称。打开卡片检查说明、Skills、场景和执行配置。

![插件视图与启用开关](/img/data-agent/zh-CN/plugins.png)

开关控制是否启用。“已安装”是已启用视图，关闭后包仍可能保留在注册表。已启用的官方首页插件显示为场景按钮。

## 开始任务

回到首页选择场景，绑定数据库或上传需要的文件，选择推荐问题。专家问题通常需要补充原始 SQL 或表清单再发送。

`/sql-diagnose`、`/data-dictionary` 等快捷命令帮助选择任务方法，不替代资源、工具权限或可用模型。

## 导入团队能力包

点击添加操作，选择包含支持 manifest 或旧版 suite 定义的 ZIP。检查包的提示和脚本来源，确认导入卡片、资源与启用状态。

企业视图用于寻找团队导入。停用不等于删除；卸载用于移除允许卸载的导入包。以界面提供的动作范围为准，内置包不一定具有相同移除操作。

## 检查依赖

运行前确认模型、数据库、文件、工具环境与所需 MCP 服务。插件导入或启用不意味着依赖已配置。
