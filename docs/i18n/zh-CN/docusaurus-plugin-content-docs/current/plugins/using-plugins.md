# 使用插件

## 查找与检查

从侧栏**专家套件**进入插件中心，浏览**官方推荐、企业专属、已安装、市场**视图，按能力分类筛选，或搜索插件、能力和业务场景。

![带有场景图标与能力筛选的插件目录](/img/data-agent/zh-CN/plugins.png)

点击插件名称打开详情抽屉。**概览**展示预期产物、示例问题与包内说明；**技能**展示快捷命令和技能；**配置**展示声明的执行方式、允许/排除的工具与默认上下文。这些声明不代表工具已经可用或权限已被强制执行。

![插件详情抽屉与预期产物](/img/data-agent/zh-CN/plugins-detail.png)

点击**管理**显示目录中的启用开关，也可以在详情抽屉底部调整状态。**已安装**包含已启用、已停用和已安装但未启用的插件。已启用的官方首页插件显示为场景按钮。

![管理模式中的插件启用开关](/img/data-agent/zh-CN/plugins-manage.png)

## 开始任务

点击目录中的**使用**。包含多个命令的插件会打开**技能**页签，供你选择命令；只有一个命令的插件直接进入首页。首页输入框旁会显示选中的插件及对应命令。

也可以在首页选择场景，或通过输入框的 **+ → 专家套件**选择已启用插件。各处使用相同图标和名称标识当前选择。

![从输入框上下文菜单选择已启用插件](/img/data-agent/zh-CN/plugin-picker.png)

绑定数据库或上传需要的文件，再选择推荐问题或填写自己的需求。专家问题通常需要补充原始 SQL 或表清单再发送。

`/sql-diagnose`、`/data-dictionary` 等快捷命令帮助选择任务方法，不替代资源、工具权限或可用模型。

## 导入团队能力包

点击**添加 → 导入插件 ZIP**，选择包含支持 manifest 或旧版 suite 定义的 ZIP。**添加 → 智能创建**会打开首页的插件创建任务。检查包的提示和脚本来源，确认导入卡片、资源与启用状态。

**企业专属**视图用于寻找团队导入。停用后不能在新任务中选择插件，包不会因此删除。卸载时打开详情抽屉，通过右上角 **… → 卸载**查看确认提示；包文件仍保留在磁盘，能否移除以服务端响应为准。

## 检查依赖

运行前确认模型、数据库、文件、工具环境与所需 MCP 服务。插件导入或启用不意味着依赖已配置。
