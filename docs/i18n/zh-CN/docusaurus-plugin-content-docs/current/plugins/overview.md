# 插件中心

插件把一类任务的方法封装为可复用能力包，组合场景提示、Skills、资源与 DB-GPT 配置，让用户从成熟方法开始，而不必每次重新编写长提示。

中文界面目前从侧栏**专家套件**进入，页面展示插件目录。

![官方插件目录](/img/data-agent/zh-CN/plugins.png)

| 组成 | 描述什么 |
| --- | --- |
| 插件 | 场景能力包，例如 SQL 优化专家 |
| Skill | 一种聚焦方法及可选脚本、资源 |
| 工具 | Agent 可调用的执行操作 |
| Flow | Agent 责任、依赖与控制节点构成的图 |

插件可包含多个 Skill，Skill 指导工具使用，Flow 为节点配置 Skill 和资源。名称本身不授予数据库权限，也不批准变更。

先选择[官方插件](./official-plugins.md)，再按[使用指南](./using-plugins.md)启用、导入或移除。开发自己的插件请看[包格式参考](./package-reference.md)。

可以按来源、能力分类与关键词缩小目录范围。**已安装**包含已启用、已停用和已安装但未启用的插件。**市场**展示已注册的市场来源插件，没有资源时显示空状态；这不代表已具备托管市场或依赖自动安装能力。
