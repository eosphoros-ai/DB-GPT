# 工作流故障排查

按症状索引生产上真实出现过的故障。

## 全节点 0:00 标 failed，toast 给出服务端原因

流在任何节点产出 marker 前就结束了——通常是 `[SERVER_ERROR] Flow …'s dag id not found`：

- flow 处于 `developing` 状态（编辑器保存过但未部署）。打开编辑器部署，或经 flow API 重新部署；
- flow 已部署但服务进程在注册完成前重启过；`running` flow 启动时会自动重注册——重试一次，
  仍失败则检查 flow 状态徽标。

UI 会把真实原因以 toast 与答案区展示；如果看到"全红但无任何提示"，说明前端是旧构建。

## 报告节点不产 HTML / 答案里是裸 JSON

- **答案裸 JSON**：模型把最后一次工具 observation 原样粘成 terminate 结果。当前构建会把
  envelope 兜底清洗为可读文本，模板 goal 也禁止粘贴；自定义 flow 若复现，给报告 goal 加同一句
  禁令；
- **observation 里 `No HTML content provided`**：HTML 工具参数被截断（输出上限）或为空。节点
  模型调用带 16k 输出预算；若你把 `model` 覆盖为上限更小的供应商，拆分报告或简化 HTML。

## *缺参数 · 输出被截断* 徽章 + 重试

模型回合在协议中途被截断，空参调用了工具。守卫回可行动 observation，Agent 会重试——徽章是
信息性的。频繁出现说明节点 payload 过大：收紧 goal、限制行数，或提高 `max_turns`，而不是忽略它。

## `sql_query` 报数据源越界 / 不存在

节点的 `datasources` 配置就是边界：空 = 根本没有 SQL 工具；名字不在数据源注册表 = 工具构建期
失败。绑了多个数据源时工具要求显式 `db_name` 参数——接地 goal 应写明用哪个库。注意：输入框上
挂的数据库附件**不进**工作流，只有节点 config 算数。

## 模型供应商错误（402 / 401 / 429）

节点响亮失败并带供应商消息，而不是编造分析。检查模型供应商余额/配额后重跑；运行卡会显示是
哪个节点撞上的。

## 模板改了但对话里没生效

- 内置模板首次使用才实例化进 My Flows（按浏览器缓存）。改模板文件只影响新实例；模板创建参数
  变化会 bump 缓存 key，旧缓存自动失效；
- 编辑**你的实例**后必须部署（见 0:00 失败那条）。

## flow 会话用 URL 打不开

flow 运行是直播流，"从历史重放"入口尚未 shipped：会话列表能看到这轮，但深链 flow 会话会落回
首页。这是已知缺口，不是安装坏了。
