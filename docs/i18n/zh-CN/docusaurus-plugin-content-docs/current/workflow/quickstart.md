# 运行第一个 Agentic Workflow

从模板开始，先理解阶段和交付，再配置资源并运行。

## 1. 选择模板

打开**工作流 → 内置模板**。初次可选择数据库取数；数据库智能分析将任务分为语义与结构、计划、并行分析与数据质量、复核、报告。

![模板中心](/img/data-agent/zh-CN/workflow-templates.png)

点击**编辑副本**检查和修改，不改变内置模板。

## 2. 配置责任和资源

在编辑器选择流程数据源，再核对各 Agent 的数据源与工具，明确每个阶段的产物。主对话输入框绑定数据库不替代节点资源配置。

![分析模板的实际阶段](/img/data-agent/zh-CN/workflow-editor.png)

销售分析应说明期间、货币、日期格式、维度和复核方法。`Walmart_Sales` 是演示数据，不是实时经营数据。界面切换语言不会翻译已经保存的流程名称或节点提示。

## 3. 保存并发布

**保存**保留草稿，**发布**将 Flow 部署为可运行状态。仅保存未发布的 Flow 可能报“dag id not found”。

## 4. 运行范围明确的问题

从列表运行，或在输入框上下文菜单选择 Flow：

```text
分析配置的演示数据库中各门店、各月销售。
先核对日期格式，再分组；独立对账合计。
交付包含 SQL 依据、单位和数据质量限制的报告。
```

运行视图显示阶段进度。展开节点检查工具，完成后打开报告成果。

## 5. 在必要时添加 Gate

自定义 Flow 可在计划后加入 `human_confirm`，由人确认范围再执行耗时分析。它不是每个模板都必须包含的节点。
