# Flow 编辑器

编辑器将模板变成可复用流程，提供画布、Agent 属性和发布操作。

![工作流画布](/img/data-agent/zh-CN/workflow-editor.png)

## 先定义责任，再选择工具

写明阶段负责什么、输入假设、证据要求、产物格式以及不能继续时的输出，再配置节点。

| 字段 | 用途 |
| --- | --- |
| 名称 | 阶段在画布和运行视图中的业务名称 |
| Agent 类型 | 数据、知识或通用执行角色 |
| 目标 | 责任与 `Output:` 交付要求 |
| 工具与 Skill | 当前阶段可用方法和执行能力 |
| 数据源与知识库 | 节点可访问的资源 |
| MCP | 节点的外部工具服务配置 |
| 最大轮次 | 节点执行预算，1–30 |
| 并行分组 | 配置受支持的并行协作结构 |

![Agent 属性面板](/img/data-agent/zh-CN/workflow-agent.png)

工具配置和实际挂载情况决定能力范围；`Output:` 是提示约定，正确性要求见[产物契约与 Gate](./contracts-and-gates.md)。

## 连接与发布

添加任务 Agent 或开始、输出、数据入口、人工确认等辅助节点。连线表达依赖，数据交接使用上游输出并受上下文预算约束。

节点接收祖先阶段的产出；独立并行分支不互读结果。需要联合复核时，将两个分支连接到共同下游复核阶段。

保存是草稿，发布才部署可运行 Flow。模板副本不会修改内置模板，语言切换也不会翻译已保存的名称和提示内容。
