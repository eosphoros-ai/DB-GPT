# 读运行与产物

工作流的一切投影为对话里的一张运行卡，外加流尾的全局状态线。

## 运行卡

- **头部**——flow 名、进度条 `已完成 / 总节点`、耗时；
- **节点链**——按执行序每节点一个 chip：虚线灰 *待执行*、琥珀呼吸 *运行中*、绿色 *成功* 带时长、
  红色 *失败*。链在发送时即由 flow DSL 种子化，第一个节点跑完前你就能看到完整计划；
- **节点卡**——每节点一张，运行中/失败自动展开：
  - 轨迹行：💭 思考、带参数的工具调用、可折叠 👁 观察、✓ 回答；
  - 失败行：红色强调 + 折叠的错误原文，守卫/重试触发时带徽章（*缺参数 · 输出被截断*、
    *执行失败*、*重试 ×N*）；
  - 产物 chips 与查询块（见下）。
- **答案区**——卡片下方只有最后一个节点的结论文本；中间节点产出留在各自卡内，vis/产物 fence
  永不漏进正文。

## 产物

### HTML 报告

经 `html_interpreter` 渲染 HTML 的节点会登记文件产物。节点卡显示带文件名与大小的 chip：点文件名
在右栏打开交互报告预览，点下载图标保存文件。文件落在会话产物目录，仅经受限产物端点服务
（pilot 根边界）。

![右栏 HTML 预览](/img/workflow/zh/fig-05-html-preview.png)

### 查询结果集

`sql_query` 结果以结构化 chunk 传递（SQL、列、行上限 2000、截断标志、数据源）。在节点卡内渲染为
内联查询块：结果表 + 编辑重跑入口（改或不改 SQL 后经 run 端点重执行）。

![节点卡内查询产物块](/img/workflow/zh/fig-11-query-artifact.png)

## 失败语义

- 节点 raise 即红失败；下游随之失败（没有上游契约可依赖）。链 chip 与卡片状态一致；
- 守卫重试（空参、截断回合）**不算失败**：徽章记录之，Agent 通常在回合预算内自愈；
- 供应商级错误（计费/鉴权/限流）让节点响亮失败，而不是伪装成分析答案；
- 若流在任何节点产出前就结束（如 flow 被取消部署），UI 以 toast + 答案区展示真实服务端原因，
  而不是静默全红链。

## 历史

完成态运行把 marker 与产物元数据存进会话，节点卡、轨迹、产物 chips 刷新后仍在。（已知缺口：
刷新后重新挂接一个仍在服务端执行的运行尚不支持。）
