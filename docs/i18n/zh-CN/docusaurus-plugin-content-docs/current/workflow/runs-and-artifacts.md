# 运行与成果

运行卡片展示阶段链、进度、节点状态、工具轨迹与成果。先看整体进度，再展开有疑问的节点。

## 状态与工具

未到达节点显示等待执行，活动节点显示运行中，完成和失败分别标记成功与错误。人工确认节点等待决策。失败节点及依赖工作不能视为已完成。

节点详情包含工具输入、输出、SQL 结果和单次失败。查看实际工具记录，不仅看最后一句总结。供应商错误、参数截断和真正执行失败应分别定位。

## 成果

HTML 报告通过成果卡片打开预览或下载。SQL 结果展示查询、列、行及截断信息；可用的编辑重跑入口执行一条查询，不是恢复整个 Flow。只有真实生成并可打开的文件才算交付。

## 历史与恢复边界

保存消息含完整结构化 Flow 标记时，可以重建节点、轨迹和成果。旧记录或截断消息可能缺失工具输入、输出、成功状态，不能推断补齐。历史回放不重新执行任务。

刷新后重新附着活动流、断点续跑和服务重启恢复是不同能力，不应假设自动支持。修复首个失败原因后使用可用重跑操作。重启后重新注册已发布 Flow 恢复的是定义，不是中断任务。
