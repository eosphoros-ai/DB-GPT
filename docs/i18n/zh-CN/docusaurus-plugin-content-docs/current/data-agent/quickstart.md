# 第一次数据任务

本指南从已运行的 DB-GPT 开始。先完成[安装](../getting-started/index.md)，并配置支持当前任务工具的模型。

## 1. 连接数据库

打开**数据源**，添加连接并确认可以读取表。取数和分析建议使用只读数据库账号。连接成功不代表已经具备业务指标定义。

首次体验选择一个能够独立核对的小数据库。首页电商推荐问题依赖另外准备的 `Semantic_Commerce_Case` 数据库；安装 DB-GPT 不保证该演示库已经存在。

## 2. 准备业务含义

如果问题涉及统一口径，打开**语义层**，登记连接、同步元数据、审核业务定义并发布指标，具体见[语义中心上手](../semantic-center/quickstart.md)。

没有已发布定义时，让 Agent 说明缺失项并先澄清业务范围。不要将草稿默认为已批准指标。

## 3. 选择场景并提问

回到首页选择**智能取数**，通过输入框的数据源按钮绑定数据库，检查模型后发送推荐问题或自己的问题。

![智能取数入口与推荐问题](/img/data-agent/zh-CN/query-entry.png)

```text
查询2026年1月净实收并按获客来源拆分。
先读取最新已发布指标定义并说明版本，遵循支付与退款时间归属规则，
避免明细关联放大金额。输出已执行 SQL、金额（元）、口径引用和缺失证据。
```

替换为你自己的表与指标名称。电商案例是模拟数据，不用于真实经营结论。

## 4. 核验交付

展开 SQL 与工具详情，核对数据库、时间过滤、有效性条件、汇总粒度、单位、指标版本以及截断情况。打开成果文件后再确认文件已交付。

SQL 草稿不代表真实执行；看板草稿不代表所有组件校验通过；CSV 导出必须来自已执行结果，并说明导出限制。

## 5. 扩展任务

调查变化或制作看板时选择**智能数据分析**。需要重复执行、明确阶段和独立复核时使用 [Agentic Workflow](../workflow/quickstart.md)。第一次任务保持小范围，便于人工核对。
