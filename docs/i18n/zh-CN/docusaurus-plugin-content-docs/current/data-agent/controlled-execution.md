# 受控执行

控制发生在不同层次。根据任务配置所需边界，并查看实际生效配置。

| 层次 | 配置与核查 | 适用边界 |
| --- | --- | --- |
| 数据库 | 账号权限、选定连接 | 优先只读账号；语义标签不直接授予或撤销 SQL 权限 |
| Agent 工具 | 实际挂载工具、节点资源 | manifest 声明不代表所有控制已经执行 |
| 工具审批 | 生效策略、待确认调用 | 批准操作不代表其计算正确 |
| 执行环境 | 文件、网络与代码运行环境 | 隔离依赖部署配置，并非所有工具都在沙箱中执行 |
| Flow | 阶段职责、依赖、复核和 Gate | 阶段确认与单次工具审批不同 |
| 交付 | 调用记录、成果状态、截断、引用 | 自然语言总结不能替代执行证据 |

具体见[高风险工具审批](../application/high_risk_tool_approval.md)、[沙箱](../sandbox/index.md)与 [Harness](../harness/usage.md)。

## 执行前

明确数据库或文件范围、允许动作、时间范围、输出限制以及是否允许变更。SQL 优化与元数据专家通常交付只读诊断和建议；索引候选不是已经创建的索引，DDL 应进入独立变更流程。

## 执行中与交付后

阅读确认请求，再决定是否批准。检查调用失败与重试，确认成果链接可打开、结果限制明确。模型供应商失败时修复鉴权或配额再运行，错误消息不是已完成分析。

语义中心中的护栏可以记录预期规则；当前语义只读工具并不自动提供行级权限强制、基于扫描成本的审批引擎或通用 SQL 口径验证。
