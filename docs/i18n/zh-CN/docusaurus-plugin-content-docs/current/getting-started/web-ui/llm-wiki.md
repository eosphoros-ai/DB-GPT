# LLM-Wiki

LLM-Wiki 把知识空间变成一份**活的 Wiki**：Agent 阅读空间内的文档，自动生成互相链接的 Markdown 页面（实体、概念、逐文档摘要、索引目录页）与可视化链接图谱，并随新文档到达而**增量更新**。

Wiki 支持三种消费方式：逐页签浏览；任意 Agent 通过 `kb_wiki_*` 工具查询；普通知识对话亦会受益（Wiki 内容的检索分值有加权）。

## 开启 LLM-Wiki

打开空间创建向导（或既有空间的绑定流程），在 **索引方式** 中勾选 **LLM-Wiki 索引**：

![索引方式与 LLM-Wiki 配置](/images/web-ui/llm-wiki/06-index-methods-wiki-on.png)

可选调优（默认即可）：

| 字段 | 含义 |
|---|---|
| 抽取粒度 | 聚焦（少而精）/ **标准**（推荐）/ 穷举（页面最多） |
| 生成模型 | 默认使用系统首个可用模型 |
| 单次入库最大新增页 | 每批文档的成本上限（默认 8） |
| 内容侧重指令 | 自由文本，例如「面向新员工入职组织内容；优先表格」 |

## 生成 Wiki

文档是触发器。以下任一情况都会启动一次 30 秒防抖的生成——无需手动点击：

- 绑定外部数据源（首拉立即执行，之后按计划同步）
- 在文件视图上传 / 重新同步文件

整体重建（例如修改 Wiki 设置后）请打开空间 → **Wiki** 页签 → **生成 / 重建**：

![Wiki 页签与目录树](/images/web-ui/llm-wiki/08-wiki-tab.png)

## 浏览 Wiki

**Wiki** 页签展示空间的 Wiki：

- **目录树** — 最多两级的文件夹，页面行带类型（概念/实体/摘要…）与版本徽标；搜索框可直接定位页面。
- **阅读器** — 每页渲染别名、来源文档与被链接；正文中的 `[[链接]]` 可在页面间跳转。

![阅读器中的概念页](/images/web-ui/llm-wiki/11-wiki-reader-page.png)

- **Wiki 图谱** 页签 — 页面之间的链接图谱；单击节点预览，双击切换邻域中心。

![Wiki 图谱](/images/web-ui/llm-wiki/12-wiki-graph.png)

## 编辑与版本历史

每个页面都有修订历史。Agent 编辑、生成管线、人工编辑均以来源标记记录（自动生成 / Agent 编辑 / 手动编辑），可回滚到任意历史版本（回滚本身也是一次新版本）。

点击 **编辑** 进行内联编辑（乐观锁——若他人先保存，会收到带「加载最新/覆盖」选项的 409 提示）。

## Agent 消费 Wiki

空间开启 LLM-Wiki 后，绑定该空间的 Agent 会自动获得三个只读工具（wiki 未开启的空间不挂载）：

| 工具 | 用途 |
|---|---|
| `kb_wiki_index` | 目录概览（文件夹 + 页面 + 一句话摘要） |
| `kb_wiki_search` | 按关键字搜索页面 |
| `kb_wiki_read_page` | 按 slug 读取页面（`'index'` = 目录页） |

空间内部流程（空间详情页的对话 / 维护型 Agent）还可通过
`kb_wiki_write_page` / `kb_wiki_replace_text` **写入** Wiki——所有写入都标记为 Agent 编辑并可回滚。

在 Data Assistant 中选中 wiki 空间后，知识库段落会列出这些工具；询问空间的整体知识结构时，Agent 会优先调用 `kb_wiki_index`。

## 选择 wiki 空间

助手的选库弹层会在 wiki 空间上显示 **📖 Wiki** 徽标，一眼识别哪些库带策展 Wiki 知识：

![选库弹层的 Wiki 徽标](/images/web-ui/llm-wiki/16-kb-picker-badge.png)

## 生成原理（简版）

1. 文档照常分块/向量化；每次同步会进入防抖队列。
2. 管线逐文档抽取页面候选 → 分块引用取证 → 合并重名 → 规划两级目录 → 按「编译器而非作者」原则增量改写每页。
3. Finalize 阶段重建索引目录页、清理死链、注入交叉链接，并将页面同步进检索索引（知识对话中加权 1.3×）。

生成结果在目录树中按「索引方式」分组可见；**摘要** 页签保存逐文档摘要页。
