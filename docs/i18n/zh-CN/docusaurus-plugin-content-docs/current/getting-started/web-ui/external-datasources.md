# 持续同步外部知识来源

来源绑定将知识空间连接到外部文档平台或订阅源。资料经常更新时，可以通过同步减少手动上传副本带来的知识过期问题。

需要检查三个阶段：**拉取来源内容 → 处理文档 → 启用时生成 Wiki 页面**。来源同步成功，不代表索引或 Wiki 生成已经完成。

## 选择来源

打开[知识空间](/docs/getting-started/web-ui/knowledge-base)，进入**数据源**标签并点击**绑定数据源**。也可以在创建空间时选择外部来源卡片，再继续完成绑定。

![尚未添加绑定的数据源标签](/img/data-agent/zh-CN/knowledge-sources.png)

向导展示当前部署已注册的连接器，以及本地文档和文本的录入入口。

![来源类型与四步绑定向导](/img/data-agent/zh-CN/knowledge-binding.png)

截图使用中文界面，部分连接器描述与已有资源名称保留原始语言。本例没有绑定外部账号。

| 来源 | 内容与访问准备 |
|---|---|
| **飞书知识库** | 应用可见的知识库资源；准备 App ID、App Secret、文档权限及资源访问权限 |
| **飞书云盘** | 选定文件夹与受支持的文档；准备应用凭据及文件夹访问权限 |
| **语雀** | 选定个人或团队仓库中的文档；准备有访问权限的 Token |
| **RSS / Atom** | 可访问订阅地址中的文章 |
| **本地文档 / 文本片段** | 直接向空间上传文件或粘贴内容 |

转换结果取决于连接器与资源类型。文档中出现电子表格或多维表格的链接，不代表其全部表内数据已被导入，需要检查生成的文档内容。

## 完成绑定

1. **选择类型**：选择外部平台。
2. **凭据配置**：填写所需字段并验证访问。
3. **选择范围**：选择需要同步的资源。先从小文件夹或仓库开始，确认目标文档可见。
4. **同步策略**：设置连接器提供的同步周期、模式、冲突处理及删除行为，再完成向导。

| 配置 | 如何选择 |
|---|---|
| 同步周期 | 首次使用手动同步核验范围，确认后再启用周期同步 |
| 增量 / 全量 | 在支持时拉取变化，或扫描所选范围 |
| 冲突处理 | 决定是否更新已有本地内容，或跳过 |
| 来源删除 | 决定是否将来源中的删除同步到本地，并核对连接器的全量同步行为 |

:::info 完成范围配置
当前向导可能在凭据验证后、范围选择完成前保存绑定。此时关闭向导，可能留下未完成配置的绑定。请返回**数据源**检查，继续完成配置或删除未使用的绑定。未选择目标时，首次拉取可能被跳过。
:::

完成后检查绑定状态和同步日志。在**文件视图**中确认新增或更新的文档，再检查切片和处理状态。启用 Wiki 时，另行检查生成结果。

## 维护绑定

| 操作 | 作用 |
|---|---|
| **立即同步** | 按配置范围执行同步 |
| **暂停 / 恢复** | 停止或恢复周期同步 |
| **同步日志** | 查看拉取、新增、更新、跳过、失败、删除等统计及错误 |
| **删除** | 删除绑定，保留之前已同步的文档 |

绑定可能处于启用、暂停、运行或错误状态。判断本地资料是否最新时，检查上次成功同步时间及错误。暂停或删除绑定，不会自动停用已经导入的文档。

## 常见问题

| 现象 | 检查方向 |
|---|---|
| 凭据验证失败 | 应用或 Token 有效性、所需权限、需要时的应用发布以及资源授权 |
| 资源树为空 | 应用或 Token 能否看到目标资源 |
| 已有绑定但没有文档 | 所选目标、同步模式、日志及服务端网络 |
| 平台限流（`HTTP 429`） | 平台限制、同步频率和并发客户端 |
| TLS 校验失败 | 配置受信任的企业 CA，例如 `DB_GPT_KS_CA_BUNDLE`，并检查服务端证书信任 |
| 凭据加密错误 | 服务端知识来源加密配置及持久化密钥是否可用，结合日志排查 |
| 同步成功但问答或 Wiki 失败 | 文档处理、存储与 Embedding 依赖，以及大语言模型服务 |

接入新平台时，可参阅仓库中的 `docs/design/datasource-connector-dev-guide.md`。连接器注册让平台可以被发现，其权限和同步行为仍需验证。
