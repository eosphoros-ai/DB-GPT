# Upgrade To v0.8.2

## 概述

本指南适用于从 **v0.8.1** 升级到 **v0.8.2** 的用户。

- **SQLite 用户**：升级前请备份元数据库。新增的元数据表和字段会在 DB-GPT 服务启动时自动创建。
- **MySQL 用户**：需要执行数据库迁移，请使用 `assets/schema/upgrade/v0_8_2/` 目录下的增量升级脚本。

## 准备工作

### 备份数据库

:::warning
为防止数据丢失，**请务必在升级前备份元数据库**。请根据数据库类型选择合适的备份方式，例如 MySQL 使用 `mysqldump`，SQLite 直接复制数据库文件。
:::

### 确认升级脚本

v0.8.2 的升级脚本维护在仓库的 [`assets/schema/upgrade/v0_8_2/`](https://github.com/eosphoros-ai/DB-GPT/tree/main/assets/schema/upgrade/v0_8_2) 目录下：

| 脚本 | 用途 |
| --- | --- |
| `upgrade_to_v0.8.2.sql` | 用于将已有的 v0.8.1 MySQL 元数据库增量升级到 v0.8.2。 |
| `v0.8.2.sql` | 用于全新安装的完整 v0.8.2 Schema。 |

从 v0.8.1 升级时，请使用 `upgrade_to_v0.8.2.sql`。不要在已有数据库上执行完整 Schema 文件。

## 升级步骤

### 第 1 步 — 停止 DB-GPT 服务

使用与启动时相同的方式停止正在运行的 DB-GPT 服务。

### 第 2 步 — 升级数据库

v0.8.2 的元数据升级包含 1 个新增字段、1 个字段类型调整和 4 张新增元数据表。

**字段变更**

| 对象 | 变更 | 说明 |
| --- | --- | --- |
| `knowledge_space.index_methods` | 新增可空 `varchar(500)` 字段 | 存储所选索引方式的 JSON 列表（例如 `["VectorStore", "FullText", "KnowledgeGraph"]`），供 Agentic 知识库检索使用。 |
| `gpts_messages.content` | 字段类型调整为 `longtext` | 支持存储更长的 Agent 消息和执行报告；同时修复使用 `v0.8.1.sql` 全新安装的数据库中该字段仍为 `text` 的问题。 |

**新增表**

| 表名 | 说明 |
| --- | --- |
| `dbgpt_session_file` | 存储归属于用户的会话与定时任务文件元数据，包括稳定的公开文件 ID、受管存储 URI、检查状态和任务文件来源关系。 |
| `code_graph_vertex` | 存储 AST 提取的代码节点（类、函数、模块等），用于代码图谱检索。 |
| `code_graph_edge` | 存储代码节点之间的结构关系（包含、调用、导入等）。 |
| `code_graph_meta` | 按知识空间存储图谱元数据，包括节点/边数量、构建来源和构建状态。 |

对于 MySQL 元数据库，请执行增量升级脚本：

```bash
mysql -u <user> -p dbgpt < assets/schema/upgrade/v0_8_2/upgrade_to_v0.8.2.sql
```

如果你的元数据库名称不是 `dbgpt`，请将命令中的 `dbgpt` 替换为实际数据库名，或在正确的数据库上下文中执行该 SQL 文件。

:::tip
增量脚本开头包含 `USE dbgpt;`。如果你的元数据库使用了其他名称，请在执行前修改这一行，或先在 MySQL 会话中选择正确的目标数据库。
:::

### 第 3 步 — 安装依赖

根据你的安装方式更新依赖。如果你是从源码安装并使用默认配置，请执行：

```bash
uv sync --all-packages
```

如果需要使用 v0.8.2 新增的可选集成，请按需安装对应 Extra：

```bash
# Agentic 知识库检索和 RAG 依赖
uv sync --all-packages --extra "rag"

# Milvus 向量存储
uv sync --all-packages --extra "storage_milvus"
```

### 第 4 步 — 启动 DB-GPT 服务

使用你常用的方式重新启动 DB-GPT 服务。

启动后建议验证：

- 历史对话和知识空间可以正常加载。
- 可以在一个对话中上传、预览、移除和分析多个文件。
- 从含附件对话创建的定时任务可以访问冻结后的任务文件。
- Agentic 知识库检索可以使用已配置的索引方式完成检索，并展示来源引用。
- 并行子 Agent 任务和交互式问题可以在前端正确更新。

## 回滚说明

如果升级失败，请停止 DB-GPT 服务，并使用升级前的备份恢复元数据库。由于 v0.8.2 涉及元数据 Schema 变更，不建议继续运行处于部分升级状态的数据库。
