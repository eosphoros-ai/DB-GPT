DB-GPT · LLM-Wiki 前端设计稿

对标 WeKnora「Wiki 模式」的交互设计，采用 DB-GPT 本分支 OpenCode 设计语言（smoke 暖灰面板 + cobalt 蓝主色）。
配套方案文档：docs/design/llm-wiki-upgrade-plan.md · 示例语料沿用 WeKnora 演示数据（星云科技员工手册），便于与原版逐屏对比。

SCREEN 01
Wiki 浏览器
知识库详情页「文档 / Wiki / 图谱」三 Tab。左侧目录树（懒加载 + 类型徽标 + 计数），右侧阅读器渲染 [[双向链接]]，底部展示被链接与来源文档；顶部常驻生成进度与问题量。
SCREEN 02
知识图谱
力导向链接图（overview top-N / ego 邻域两种模式）。图例可点选过滤页面类型；搜索定位 flyTo；右抽屉预览页面 + 展开邻居 / Bloom 前沿渐进加载，保持既有布局不跳动。
SCREEN 03
版本历史与回滚
右抽屉双栏：版本列表（自动生成 / Agent / 手动编辑来源可辨）+ 行级 diff（增量 vN-1→vN / 对比当前 / 原文三视图，字段级分块，无变更自动隐藏）。回滚以新编辑落地，可再回滚。
SCREEN 04
开启与生成配置
KB 编辑弹窗内嵌 Wiki 配置区：启用开关、抽取粒度（聚焦/标准/穷举）、生成模型、单次入库页数上限、内容/抽取自定义指令与成本提示；KB 列表卡片的 Wiki / 生成中 徽标态。

🎨 视觉规范

  • 面板：smoke 暖灰 #131010 / #1b1818 / #252121，描边 #343030
  • 主色：cobalt #034cff（对齐 opencode-theme.css / tailwind primary #0069fe）
  • 页面类型色：摘要 #4da3ff · 实体 #34d399 · 概念 #f5a623 · 综合 #a78bfa · 对比 #f87171 · 索引 #8e8b8b
  • 编辑来源：✦自动生成（灰紫） / ✎手动编辑（中性） / Agent（紫） / revert（黑名单色）
  • 设计稿所有 token 收敛在 styles.css :root，切浅色主题仅需替换 surface/text 两组变量

🧩 与 WeKnora 的复用对照

  • 直接移植：LCS 行 diff、字段 diff 组装、目录展开状态机、状态刷新判定（4 个纯 TS 文件）
  • 范式沿用：三层轮询（stats 5s × 父子两级 + 文档解析联动）、409 冲突提示、请求序号防竞态
  • 结构优化：WeKnora WikiBrowser 单体 6593 行 → 拆分为 browser/sidebar/tree/reader/markdown/graph/drawer 8 个组件，graph 渲染器独立成纯 DOM 模块
