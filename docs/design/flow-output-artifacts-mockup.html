5落地清单(实现备注)

  • DSL/编辑器:nodes.py report 节点 config 增 formats: list(markdown/html/pptx/xlsx,默认 [markdown, html]);PropertyPanel 渲染多选 chips;compiler 把 formats 传进报告 operator。
  • 报告 operator(operators/report.py 扩展或新 HOReportArtifactsOperator):markdown 结论 → ① HTML:模板 + 上游图表 png(matplotlib 落盘 → /images/ URL)+ 表格;② PPTX:python-pptx 标题页/结论页/每图一页/数据页;③ XLSX:pandas ExcelWriter(openpyxl) 写 原始数据(共享 df)/ 各图聚合 / 指标汇总 三个 sheet;全部写 pilot/tmp/<conv>/outputs/。
  • visualize operator:gpt-vis dashboard 落盘 dashboard.html;每图 matplotlib png 落盘;登记产物。
  • 帧协议:build_step_marker 增 artifacts 字段(name/type/path/size/meta);TS 类型同步;artifact-file 端点已可服务 pilot 内文件,下载零新端点;预览增 artifact-preview(xlsx/pptx 元信息)。
  • 前端:FlowRunView 节点卡 chips(预览/下载);结束产物条 + 画廊「flow 输出」分组复用 ArtifactCards;xlsx 预览面板(sheet 页签表格)、pptx 元信息面板进 ArtifactRail PreviewBody。
  • 失败语义:单格式失败 → chip 红 + tooltip,节点仍成功;全失败 → 节点 failed(沿用上一轮的诚实失败原则)。
