设计标注（对照 Codex / OpenCode 原则）
  1. 单流为主：用户消息 → 意图行 → 工具组 → 产物卡 → 答案，一轮内线性阅读，无三套重复表征。
  2. 渐进披露：reasoning 一行"思考 6s"；工具默认折叠成 28px 行，同类调用分组（sql_query ×8）。
  3. 行内 gist：摘要取 SQL 首行/对象路径，不取输出碎片；状态=微图标+耗时，不用彩色徽标。
  4. 产物一等公民：HTML/图片/文件在流内即时插卡；右栏是按需查看器，无内容时不存在，主流全宽。
  5. 内容卫生：流内永不出现 {"chunks": 信封；HTML 只进产物卡与沙箱预览，不进文本行。
  6. 全局状态线：流尾一行汇总轮次/调用数/耗时，运行态为 shimmer + 实时计数。
  7. 产物三层：目录级（技能包卡：同根 ≥3 文件且含 SKILL.md 聚合）→ 文件级（md/xlsx/docx 按扩展名图标）→ 兜底级（本回答 summary 只进画廊不进流内），保证每次对话都有产物。
