DB-GPT · 任务流程（TaskFlow） 产品改造设计稿

废弃旧 AWEL Flow 编辑器的产品形态（节点即算子、参数即元数据），保留 AWEL 引擎内核；
以「数据分析」为唯一场景重新包装：粗粒度节点 + 内置模板 + 对话内一键调用 + 自然语言改流程。
配套方案文档：docs/design/taskflow-redesign-plan.md · 视觉沿用首页 Manus 浅色语言（白底 / 浅灰侧栏 / 蓝主色 / 黑主按钮）。

SCREEN 01
任务流程编辑器
三栏布局：左侧 12 个粗粒度节点（数据来源 / 分析计算 / 流程控制 / 输出四组），中间线性画布（连线上 + 号插入节点），右侧属性面板只暴露产品级配置（模型、分析要求、并行 / 重试），顶部常驻「自然语言改流程」入口。
SCREEN 02
首页对话 · 选择任务流程
首页输入框 + 菜单新增「任务流程」分组：内置模板（数据分析流 / 通用快速取数 / Excel 透视分析）与我的流程混排；选中后以 chip 挂在输入框上，附默认数据源上下文，发送即按流程执行。
SCREEN 03
任务流程管理
内置模板与我的流程分区卡片：节点链缩略图、运行次数 / 成功率、发布状态；内置模板只可「编辑副本」，我的流程支持编辑 / 发布 / 导入导出 dbgpts。
SCREEN 04
对话内运行态
流程进度卡（步骤时间线 + 每步可展开 SQL / 数据预览 / 结论摘要）+ HITL 人工确认横幅 + 右侧 Artifact 面板（图表 / 报告草稿 / 中间数据），复用首页 Manus 双栏体验。
SCREEN 05
编辑器 · Agent 节点（多 Agent 串联）
新增 Agent 节点类型：可连续串联 2 个、3 个或更多 Agent，每个 Agent 看到全部上游产出作为上下文；属性面板 = 指派 Agent（画像）+ 模型 + 目标 Prompt + 工具/MCP 连接器勾选 + 最大回合数。
SCREEN 06
对话内运行态 · Agent 节点实时轨迹
Agent 节点完成即展开内部 ReAct 小步骤（思考 → 工具调用 → 观察 → 回答）；运行中的节点显示当前动作行与回合数；已完成的 Agent 产出增量可见。

🎨 视觉规范

  • 面板：白底 #ffffff / 浅灰 #fafafa #f5f5f4，描边 #e7e5e4
  • 主色：蓝 #2563eb（首页 badge / avatar 一致）；主按钮黑 #1c1917
  • 节点分组色：数据来源 蓝 · 分析计算 紫 · 可视化 青 · 流程控制 琥珀 · 输出 绿
  • 所有 token 收敛在 styles.css :root

🧩 与旧 Flow 编辑器的对照

  • 旧：/construct/flow/canvas，节点 = AWEL 算子描述符，参数表单由 ui_type 驱动，资源/算子/变量全暴露
  • 新：节点 = 产品能力（数据库查询 / 智能分析 / 可视化…），属性面板只放业务配置；AWEL 细节下沉「开发者模式」
  • 入口迁移：/construct/flow → 侧栏「任务流程」；chat_flow 场景不变，select_param 仍传 flow uid
