## 实现边界核对

- 语义定义、指标创建与发布请求体对照 `semantic/api.py` 和 `semantic/service.py`。
  当前指标界面提供检查与发布，公共 API 没有通用指标修改路由；自定义准备使用维护流程。
- 语义只读工具读取已发布内容与精确版本，搜索以关键词/别名为主。
  UI 展示关系、样例、护栏不代表已强制执行行级权限、SQL 口径验证或持久化版本 pin。
- 工作流上下文对照 `taskflow/compiler.py`：任务接收祖先成果，独立并行分支不互读，
  共同下游复核阶段可以接收两个分支的成果。
- `Output:` 是提示契约；独立复核、确定性检查、人工阶段 Gate 和工具审批分别说明。
  历史回放不等于新的实时运行，失败定位不等于断点恢复。
