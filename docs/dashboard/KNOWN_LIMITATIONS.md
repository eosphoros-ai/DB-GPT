# 已知限制

- SQLGlot 26.13.2 不识别 Vertica、MaxCompute、GaussDB、openGauss、OceanBase。Dashboard 在执行前返回不可重试的 `unsupported_data_source`，不回退到通用方言。解析器支持的类型仍需在目标数据库上单独验证。
- 新建页包含规划、确认与生成流程，刷新会丢失页面内尚未保存的输入和选项；已保存资产可由看板列表访问。
- 模型可能生成结构合法、业务含义错误的输出。生成结果需要业务审核；固定题目回放不能代表通用生成成功率。
- 默认关闭布局模板入口，需按部署需求显式开启。
- 固定快照筛选限于已物化维度；工程 ZIP 仍依赖后端。持续分享需要受控查询数据源，轮询不保证实时性。
- 数据库取消、生产身份、多租户、外部连接器授权、分享密钥及长期负载须在目标环境验证。原子密钥创建需要硬链接支持；文件系统不支持时会明确报错，也可由部署环境配置 `DBGPT_SHARE_ENCRYPTION_KEY`。
- SQLite 沿用上游启动时的建表与自动迁移；MySQL 使用全量建表 SQL 或 `assets/schema/upgrade/dashboard/upgrade.sql`。不要依赖请求路径自动建表。
- Dashboard 的 DuckDB 查询仅允许已注册表，不允许文件路径或表函数直接读取外部文件。上传分析沿用部署指定的 `SANDBOX_RUNTIME`，不会单独切换到 Lyric。
- SQL 表白名单按查询作用域校验；带 schema/catalog 的表名需要完整名称授权，不能借同名 CTE 或另一库的同名表绕过检查。连接器仅返回未限定表名时，查询也应使用这些未限定表名。
- 刷新超时会阻止后续发布，并在发布事务提交前再次检查。已运行的数据库调用不能被 Python 强制终止，调度器等待工作线程退出期间持续续租；失去租约会取消执行。应同时配置数据源自身的查询超时。
- 生产协作需要 Redis；缺少配置时仅协作接口返回不可用，普通聊天与看板服务仍可启动。
- 历史分享未记录创建者时，由可验证的会话所有者管理。旧会话文件继续支持 `pilot/data/<conv_uid>`，但需能核验会话归属；不会将显示名推断成用户 ID。私有数据源仍按稳定用户 ID 授权，跨用户复用须先由部署方调整数据源权限。
- 真实 Walmart 源数据与合成演示数据分开。来源核验不代替再分发授权，合成数据不代表真实业务总额。

具体测试版本、通过和未覆盖范围见 [PR #3278](https://github.com/eosphoros-ai/DB-GPT/pull/3278)。
