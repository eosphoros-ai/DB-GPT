# 业务演示指南

按 [Walmart 零售案例](demos/walmart.md) 和 [Apple 财务案例](demos/apple.md) 准备。两个案例通过图文说明数据来源、制作、编辑、发布和核验步骤，可直接跟随文档复现。

## 建议顺序

1. 说明业务问题、数据粒度、来源及金额单位。
2. 从“数据看板”进入“新建看板”，选择来源、输入需求、检查无 SQL 规划，再确认生成并打开编辑器。
3. 打开一个组件，展示查询、参数、输出映射和真实结果。
4. 修改标题或布局，保存并重开；展示修订一致性。
5. 操作案例声明的筛选器，解释应改变和应保持不变的指标。
6. 选择固定快照发布，在无登录窗口核对结果；持续分享另用独立可变测试源演示。

## 演示前核对

记录当前代码版本、数据源、模型及提示，检查预期值。真实 Walmart 库和可复现合成库不可互换；Apple 财年与自然年不可混用。分享演示材料时隐藏有效凭据、完整生产分享令牌及个人资料。

模型不可用时可以展示明确标注的既有资产或固定 Schema，不能把它表述为现场生成成功。保存、发布、筛选或数据权限失败应留下真实记录。最终版本完整彩排状态见 [验证说明](VALIDATION.md)。
