## Dashboard 与必要共享接口

- Schema、规划确认、只读 SQL 与方言绑定、权限、资产/修订、批注与修改提案、模板、查询刷新、固定与持续分享、18 个迁移以及打包资源。
- 新建入口 `/dashboards/new/`：选择既有数据源或上传 CSV/Excel、使用已配置的模型、确认规划、生成后进入独立编辑器。原侧栏仅增加一个看板入口；主题变量限定在 Dashboard 路由。
- 看板刷新计划需要统一任务服务；规划与重放需要聊天执行器；上传数据集和问答确认需要会话/附件接口及生命周期处理。相应服务和回归测试随候选保留，不视为可随意删除的最后一个可选依赖。
- 官方安全修复及上传、知识空间、身份和资源作用域的原有约束保留。来源对话沿用原站点路由；看板编辑在独立编辑器中完成。

## 排除范围

默认模型/provider 切换、首页重写、全站主题与导航重排、`dashboard-showcase`、独立文档发布 action 升级、DSML 扩展、shell/sandbox 变更、全站会话保留 100 条的产品策略，以及个人结项 PDF/Word/ZIP 均不在候选范围。

原首页内嵌编辑器、统一上传队列和多套全站主题的专用浏览器用例留在完整集成档案。Dashboard 编辑器、图表、模板和分享用例保留；确认/超时用例已改用新建入口，验证业务行为不变。不同入口的证据不互相冒充。

三个兼容迁移只改文件名，保留已部署数据库中的 revision 字符串。分享密文表由独立迁移管理；请求路径不建表。更多运行边界见 [验证说明](VALIDATION.md) 与 [已知限制](KNOWN_LIMITATIONS.md)。
