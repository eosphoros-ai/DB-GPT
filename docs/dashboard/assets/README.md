# Dashboard illustrations

The repository keeps two design diagrams (`architecture.png`, `lifecycle.png`)
and one representative screenshot for each business case:

- `walmart-core-desktop-20260929.png`: synthetic Walmart retail example.
- `apple-core-desktop-20260929.png`: Apple financial example.

These dated screenshots illustrate the cases; they are not evidence that the
current commit passed a browser test. Fresh test screenshots and traces belong
in the test output directory. The template gallery uses labeled SVG layout
illustrations and renders query previews from the selected source.
