# Screenshot assets

`walmart-editor.png`, `walmart-public.png` and `apple-financial-public.png` are
generated by the deterministic standalone lifecycle test. They use the
database-backed snapshot created by `examples/dashboard/build_demo_snapshots.py`;
no model key or production database is required.

`walmart-task-manual-edit.png` and `walmart-task-annotation.png` are generated by
the task-centric lifecycle test. They prove that the chat and Dashboard remain on
the same page, the per-widget pencil opens only that widget's settings, and the
same action location becomes an annotation control while annotation mode is on.

Regenerate them from `web/` after starting the built site:

```powershell
$env:DASHBOARD_E2E_BASE_URL = "http://127.0.0.1:5671"
npm exec playwright -- test tests/dashboard-e2e/dashboard-deterministic.spec.ts `
  --config playwright.dashboard.config.ts

npm exec playwright -- test tests/dashboard-e2e/task-centric-dashboard.spec.ts `
  --config playwright.dashboard.config.ts --grep Walmart
```
