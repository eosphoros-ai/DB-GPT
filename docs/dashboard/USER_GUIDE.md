# 看板用户指南

## 1. 让数据助理生成

1. 从侧栏进入“数据看板”，点击“新建看板”，在 `/dashboards/new/` 选择已注册的数据库或上传 CSV/Excel 文件。
2. 用业务语言说明主题、指标、维度和筛选要求。
3. 生成卡会先展示不含 SQL 的指标、维度、筛选器和图表计划。
4. 检查计划：合适就点“确认并生成 SQL”；需要调整就点“修改计划”，补充自然语言要求后发送。
5. 确认后的新回合才会逐组件生成、校验和试运行 SQL。
6. 如果有局部失败，先检查组件错误及草稿是否实际保存；候选查询成功不等于生成资产已保存。
7. 草稿生成后，点击生成卡片中的“查看看板”，进入独立编辑器。
8. 完成编辑并保存后，可从“数据看板”列表重新打开该资产。刷新新建页会清空页面输入和选择；离开前应打开生成的草稿并保存。

“确认”不是装饰按钮：服务端会校验看板 ID、修订号和用户回合，Agent 不能在第一次规划时绕过它直接生成 SQL。确认时请保留原计划的数据源选择。

推荐提示词结构：

```text
请基于当前数据库生成【主题】看板。
核心指标：【指标】。
分析维度：【维度】。
全局筛选：【筛选器】。
至少包含：【组件】。
所有口径和数据粒度写在看板说明中。
```

Walmart 演示提示：

```text
请生成 Walmart 门店经营看板，包含总销售额、月度销售趋势、门店排行、
节假日销售占比和销售明细；提供日期范围、门店多选和节假日类型筛选。
```

财务演示提示：

```text
请生成 Apple FY2022–FY2024 财务看板，包含年度收入、收入与利润趋势、
产品收入结构、负债与股东权益占比和核心财务指标明细；金额单位为百万美元，
注明 SEC 10-K 数据来源。
```

generated 草稿会被保存以便任务恢复，但不会出现在“数据看板”。第一次明确点击“保存”后，它才成为 saved 资产并进入资产库。

## 2. 编辑器区域

看板详情页提供独立编辑器，可折叠组件库和属性设置以扩大画布。来源对话链接沿用 DB-GPT 原有对话页面；编辑操作在看板详情页完成。

### 左侧

- 添加指标卡、折线图、柱状图、饼图和明细表；
- 添加日期范围、单选和多选筛选器；
- 点击筛选器进入设置；
- 删除筛选器时，相关 Widget 参数映射会同步移除。

### 中间

- 查看当前筛选数据；
- 拖动组件标题栏调整位置；
- 拖动边缘调整大小；
- 普通模式点击组件右上角的铅笔，只打开该组件的右侧设置；
- 点击代码图标会直接定位并聚焦该组件 SQL；
- 开启“框选批注”后，铅笔位置切换为对话气泡，用于给组件或数据元素添加自然语言修改意见；
- 手机宽度下自动单列堆叠。

### 右侧

组件设置包括：

- 标题、说明和图表类型；
- 字段映射；
- 全局筛选器到 SQL 参数的映射；
- 参数化 SQL；
- 查询超时和最大行数；
- KPI 格式、折线平滑、圆环内径、表格页大小；
- 完整样式 JSON；
- 最近错误和单组件试运行。

切换图表类型时，编辑器会根据查询输出字段自动重建合法映射。例如折线图切成指标卡后会生成 `value` 映射，而不是保留无效的 `x/y`。

### 手动编辑和 Agent 批注有什么区别

- 想自己改标题、图表类型、字段映射或 SQL：不要开启批注，点击该组件的铅笔；
- 想让 Agent 理解“这一根柱子/这个组件哪里要改”：开启框选批注，选择目标，填写自然语言要求；
- Agent 只会先生成变更预览。点击“应用”前，真实草稿不会变化；不满意可直接放弃。

## 3. 筛选器和 SQL

### 日期范围

SQL：

```sql
WHERE sale_date BETWEEN :start_date AND :end_date
```

右侧设置开始参数 `start_date`，结束参数 `end_date`。

### 单选

SQL：

```sql
WHERE fiscal_year = :year
```

右侧参数名填 `year`。

### 多选

SQL：

```sql
WHERE store IN (:stores)
```

右侧参数名填 `stores`。不要手工拼接 `1,2,3`。

## 4. 保存、刷新和试运行

- **校验并试运行**：用右侧当前未保存 SQL 只执行一个组件；
- **保存**：结构校验通过后保存，并增加修订号；generated 草稿第一次保存时转为正式资产；
- **刷新**：先保存未保存修改，再用当前筛选器执行全部组件；
- 一个组件失败时，其他组件继续显示，失败卡保留错误和重试按钮；
- 页面顶部“未保存/生成草稿/已保存资产/已发布”标记反映当前状态。

如果另一个窗口先保存，当前窗口会收到修订冲突提示。重新加载会放弃本页未保存内容，决定前可先复制重要 SQL。

## 5. 发布与分享

点击“发布”，确认保存、校验及查询结果后选择数据更新方式：

- **固定发布时的数据**：冻结 Schema 和数据；公开筛选在受限冻结数据集上计算。指定历史修订不随源数据或草稿改变。
- **跟随数据源更新**：创建持续分享授权，按已发布定义更新数据；访客不能提交任意查询。草稿布局不会直接覆盖已发布定义。

最新发布别名跟随后续显式发布，与指定修订的固定历史链接区分。发布者应核对有效期与撤销状态，在无登录窗口验证实际分享页。已有授权链接能否访问、筛选能否计算，应依据对应模式逐项检查。

操作示例见 [Walmart](demos/walmart.md) 与 [Apple](demos/apple.md)，访问边界见 [安全说明](SECURITY.md)。

## 6. 常见错误

| 现象 | 原因 | 处理 |
|---|---|---|
| SQL 被拒绝 | 不是单条只读 SELECT/CTE | 删除写操作、命令或多语句 |
| 缺少参数 | SQL 有 `:name`，但筛选器/默认参数未提供 | 补参数映射 |
| 未知表/字段 | SQL 引用不属于当前数据源 | 检查真实表结构 |
| 缺少声明字段 | 查询结果列与 `output_fields` 不一致 | 修改别名或字段声明 |
| 图表映射错误 | `x/y/value/angle` 不在输出字段 | 重新选择字段 |
| HTTP 409 | 草稿被其他窗口更新 | 决定是否重新加载 |
| 发布 422 | 至少一个组件未通过完整刷新 | 逐组件试运行并修复 |
| 分享页打不开 | token 错误或链接不完整 | 从发布成功弹窗重新复制 |
