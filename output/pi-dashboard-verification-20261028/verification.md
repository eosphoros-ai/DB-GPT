## 发现和修复

原 PI 桥接层没有挂载 Dashboard 工具。修复前的真实请求虽然加载了
`build-dashboard` 指令及三份参考文件，却转而用澄清工具模拟确认，
并声称已提交方案，没有原生看板草稿。

本次接入与 DB-GPT 相同的 Dashboard 工具工厂与各阶段权限合同，补齐
持久化计划合同、数据源恢复、时间字段证据、生成时限与续跑、
生成事件和历史中的看板引用。每个看板阶段重建 PI 子进程，
使确认轮获得生成工具，避免沿用规划轮工具清单。
