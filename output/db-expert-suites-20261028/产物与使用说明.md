# DB 领域首发专家套件

本次交付两个 DB-GPT 原生套件，版本均为 1.0.0，每套包含 4 个快捷技能、工作规程、证据边界与报告模板。

## SQL 优化专家

| 对话任务 | 默认产物 | 能力边界 |
| --- | --- | --- |
| SQL 性能诊断 | 对话结论、普通执行计划查询卡片、完整诊断的 HTML 报告 | 无计划时为静态诊断；不声称已验证性能收益 |
| SQL 查询改写 | 原始/候选 SQL 代码块、修改对照、语义验证清单 | 默认不执行结果或耗时对比 |
| 索引候选评估 | 索引候选 DDL、现有索引对比、成本与测试方案 | 不建索引、不量化未经实测的收益 |
| SQL/DDL 变更评审 | 风险结论、前置条件、灰度/回退清单；完整任务提供 HTML | 只评审文本，不等同审批或生产上线 |

快捷命令：`/sql-diagnose`、`/sql-rewrite`、`/index-advise`、`/sql-review`。

例如：绑定数据库后输入“诊断下面的 SQL，输出优化报告，不实际执行原始查询”，再粘贴真实 SQL。

## 元数据与架构专家

| 对话任务 | 默认产物 | 能力边界 |
| --- | --- | --- |
| 数据字典生成 | 物理数据字典 CSV、对话预览、业务含义确认清单 | CSV 来自真实目录查询；缺失注释不补造 |
| 物理 ER 图 | 对话内可缩放 ER 图、draw.io / DBML / Mermaid / SVG / JSON 下载文件 | 推断关系为虚线，DBML 仅注释；不等同跨系统血缘 |
| 数据库结构文档 | HTML 结构文档、字典与关系；按需 CSV | 声明覆盖表、权限限制与采集时点 |
| 数据建模评审 | 模型建议、候选 DDL、取舍与迁移验证清单 | 不执行变更，不自动发布语义知识 |

快捷命令：`/data-dictionary`、`/physical-er`、`/schema-doc`、`/model-review`。

例如：绑定数据库后输入“为 orders、customers 两张表生成数据字典 CSV 和物理关系文档，推断关系单独列出”。

## 在对话中看到什么

1. 过程说明及技能读取记录，由现有对话引擎展示。
2. 元数据/普通 EXPLAIN 的工具记录和查询证据卡片。
3. 对话结论、SQL 或 Mermaid 代码块、验证清单。
4. 生成成功时出现 HTML 报告产物与 CSV 文件产物，可预览或下载；ER 任务直接展示图与格式下载入口。

不是每个问题都生成所有文件。简短解释以对话答复为主；完整诊断或文档任务调用报告工具。HTML 文件必须由工具返回 completed 状态；失败时会明确提供 Markdown 降级内容，不能捏造链接。

SQL、DDL 以可复制代码块和报告内代码段交付。ER 文件由 generate_er_diagram 生成，draw.io 可在 diagrams.net 打开编辑，DBML 可导入 dbdiagram，SVG 用于文档。暂不提供 DBeaver / Navicat 原生模型文件。CSV 工具只能导出已经执行且未截断的查询产物，不能用来导出草稿或拼接推断信息。

## 安装与运行

两个 ZIP 均可通过“专家套件 → 上传安装”单独导入。安装后在套件页或聊天输入框选择套件，并绑定已授权数据源。

初版优先 MySQL、PostgreSQL、SQLite 的物理结构与普通计划。其他数据库根据经核实的目录或用户提供 DDL/计划降级交付。元数据套件可选读取语义中心已发布定义，但语义中心不是前置条件。

两个套件均不开放 shell、代码执行或变更工具。生产账号权限、数据库端超时、连接/并发预算和查询成本控制仍需部署侧配置。套件包校验、绑定与工具验证不等于所有数据库和模型的完整端到端验收。
