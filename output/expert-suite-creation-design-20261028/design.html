产品约定

主要用户：希望把重复工作、岗位经验和业务流程固化为可复用能力的业务专家、分析师及 DBA。用户不需要了解套件文件格式。

完成条件：得到一个内容可检查、结构校验通过的套件包；用户点击安装后，套件出现在“已安装”和会话套件选择器中。需要数据库或连接器时，能清楚看到待配置项并完成配置。

描述需求 / 提供材料→对话生成→套件产物卡片→一键安装→立即使用
生成完成与安装成功是两个独立结果。生成不自动安装；安装不自动连接数据库、执行脚本或运行业务任务。卡片上的“一键安装”就是明确的安装操作入口，无冲突时不再增加确认弹窗。
范围本次设计
P0 完整闭环智能创建入口、材料与需求输入、生成与修改、套件卡片、文件与技能预览、结构校验、一键安装、重复点击处理、安装后配置与调用、历史恢复。
P1 延伸从现有套件创建副本、复杂依赖管理、已安装套件版本升级和回退、团队分享与市场发布。P0 的同名冲突通过改名另存解决。
安装范围建议[Assumption, TBD] P0 沿用当前部署实例的套件安装范围，界面明确显示实际范围。个人与团队范围应在身份和隔离能力落实后提供，不把当前实例安装包装成“仅我可见”。

智能创建入口 FR-01


套件页顶部增加“智能创建”主按钮和说明横幅。“添加”下提供“智能创建”“从文件导入”。保留现有官方、企业、已安装分类；市场仍按实际接入情况展示，不要求先建设市场才能创建套件。


点击后打开一个新对话，输入框显示可取消的绿色“专家套件创建”标识，示例提示为：“帮我创建一套专属的工作套件。我可以提供工作 SOP、业务文档或者岗位日常。”不预选具体业务场景，不自动发送示例。


普通对话中说“帮我创建一个专家套件”也可以进入创建流程；模型明确说明将产出套件，使用同一套产物与安装能力。创建模式和目标套件身份分别展示，避免把“创建者”误当成已经安装的业务套件。


“基于此套件定制”在 P1 生成新副本，显示来源与继承内容，不直接修改官方或他人的套件。创建标识支持关闭按钮和输入开头的 Backspace/Delete，遵守现有输入框取消习惯。







在对话中生成与修改 FR-02


用户提供角色、任务、步骤、资料和预期输出中的任意组合。AI 先归纳目标与能力清单；只有目标不明确、业务口径冲突或关键约束缺失时才提出针对性问题。可使用明确标注的默认方案完成初稿，不强制多轮问卷，也不要求先连接数据库。


生成过程输出可读说明：“整理你的工作流程”“拆分技能与指令”“编写技能内容”“检查引用和依赖”“生成套件包”。文件读取与写入显示可展开步骤，包含真实路径和内容；连续工具步骤沿用当前自动折叠方式。DBGPT 与 PI 使用相同的进度、产物和历史恢复体验。


内容生成要求不足时的行为


套件概览名称、用途、适用任务、安装后的使用方式；内部标识由系统生成。无法判断用途时询问；命名冲突在安装前提供改名。


技能每个技能包含触发条件、输入、步骤、允许使用的工具、输出和异常处理；不能只有标题和简介。缺少正文或关联关系无效时，不标记为可安装。


工作流程与指令指令与技能一一对应到有效目标；技能之间的先后关系、交接内容和完成条件清楚。重复指令、不存在的技能目标需修复并重新校验。


参考资料将用户选定的可复用内容整理成包内参考；说明原始资料与提炼结果的关系。无法读取材料时保留已输入需求，提示替换或跳过，不假装已经读取。


工具与资源标出需要的数据库、语义空间、连接器及输出能力；只声明真实可用或明确待补充的能力。无法映射的必要工具阻断可安装状态；缺少用户资源配置可生成完整包，安装后待配置。




用户可继续说“增加周报汇总”“把索引变更改成只输出建议”，AI 在草稿上修改并生成新修订。修改后的内容必须重新校验。生成中取消保留需求和已完成草稿；失败可重试，不安装半成品。







产物就是专家套件 FR-03


最终答案简要说明完成内容，紧接一张一等产物卡片。卡片显示套件名称、简介、技能数、指令数、版本、校验状态、资源要求和安装状态。主操作为“一键安装”，次操作为“查看内容”“继续修改”“下载套件”。普通 ZIP 链接和一段说明不足以表达这个结果。


“查看内容”打开右侧预览，分为概览、技能与指令、工作流程、文件、校验说明。点选技能能看到完整正文；文件预览能定位具体错误。预览可编辑技能正文并保存成新修订，不直接修改已安装文件。


卡片状态主操作反馈


生成 / 校验中显示过程，安装不可点击阶段与正在处理的内容。


需要修复继续修改具体文件、问题及修复入口。


可安装一键安装结构检查已通过；实际试跑是否完成独立展示。


安装中安装中，不接受重复提交保持当前卡片和预览。


已安装 · 可使用立即使用目标范围、安装版本和套件详情入口。


已安装 · 待配置配置资源缺少的必须资源及配置入口。


安装失败 / 同名冲突重试 / 改名另存不丢失产物，不覆盖原套件。




“结构校验通过”只证明包的结构、引用和工具声明有效，不代表真实任务效果已经验证。试跑必须单独由用户选择，并使用明确绑定的资源；未试跑显示“尚未试跑”。


套件包至少包含套件描述、完整技能正文、工作流程、使用说明及被引用的参考资料。凭证和临时会话数据不进入包；用户提供材料时，界面标出哪些资料会成为可分发的套件内容。下载的是卡片当前修订对应的实际完整包。







一键安装 FR-04


可安装卡片显示实际目标范围。用户点击“一键安装”，系统安装卡片上明确展示的修订；不要求用户先下载再上传，也不跳转到复杂表单。模型不能凭一句生成完成说明擅自安装。


安装前重新确认内容没有变化、校验仍有效、操作者有目标范围的安装权限、名称没有冲突。成功后同步刷新“已安装”、套件详情和会话套件选择器，并把卡片变为“已安装”。多个页面重复安装同一内容只产生一次有效安装。


无同名冲突、内容有效且所需资源已配置时，一次点击完成安装并启用。必须资源未配置时，可以安装完整套件，但保持禁用，显示“已安装 · 待配置”；配置完成后再启用。可选资源缺失只提示相关能力限制。


同名不同内容不自动覆盖。P0 提供“改名另存”并重新生成校验后的包；与官方套件同名时必须创建独立身份。P1 才提供受控升级，显示内容差异和新增资源需求，并保留旧版本供已有会话使用。


失败不留下可选中的半成品、不损坏已有套件；用户可以从同一卡片重试。安装时展示的权限声明用于说明执行边界，不会授权新的数据库、连接器或系统访问权限。







安装后立即可用 FR-05


“立即使用”打开新对话并选中刚安装的业务套件，而不是继续使用“专家套件创建”模式。指令和推荐问题从实际安装内容读取；资源未准备好时先进入配置入口，不给出可执行的误导状态。


新套件可从现有套件选择菜单调用。首页场景区继续保持初始不选中；通用自建岗位套件不默认挤入全部首页场景按钮，可在套件页和选择器发现。


创建对话刷新后恢复草稿、套件产物和校验说明。历史卡片的安装状态应查询真实安装结果：没有安装就显示“待安装”，已卸载就不显示“立即使用”，已有同名不同内容就显示冲突；旧卡片不得静默改指向新修订。







状态与边界


共同对象


对象定义与稳定规则


创建草稿用户需求、材料与生成文件的编辑对象。每次修改形成新修订，草稿不进入可调用套件列表。


套件产物一次修订生成的完整包及校验结果。内容变更后旧校验不再用于新内容。


已安装套件产物在目标范围内的安装结果；来源、作者、安装人和版本可以追溯。


业务会话引用指向当次使用的确切套件内容，保证历史可追溯。创建对话与业务执行对话区分。




两个独立状态过程


创建：草稿 → 生成中 → 校验中 → 可安装 / 需要修复。编辑可安装内容后回到草稿并重新校验；生成失败、取消后保留可恢复草稿。


安装：未安装 → 安装中 → 已安装；失败回到可重试状态。已安装套件的可用性分别是可使用、待配置、已禁用。注册表现有状态继续使用，界面按安装与配置状态派生文案。


异常规则


条件产品行为


空需求 / 不可读材料空需求提示填写；材料失败说明原因，可换材料或基于已输入需求继续。


模型中断或生成被取消显示已完成阶段，保留草稿。取消前最后一个完整的可安装修订仍可查看。


缺文件 / 非法引用 / 未知必要工具定位错误，安装不可用。修复后重新检查完整内容。


预览修改后点击旧卡片仍明确指向旧修订；如果已失效，要求打开最新产物。不会把按钮转接到未展示的新内容。


没有安装权限允许查看自己可见的产物，禁用目标范围安装按钮并说明所需权限。创建权限不等于安装权限。


套件声明新工具或外部访问明确显示依赖；配置和授权使用现有资源流程，安装不扩张执行权限。


历史产物丢失 / 包不完整显示不可安装与原因，提供基于保留草稿重新生成的入口。
