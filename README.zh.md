> **面向业务数据工作的开源 Data Agent 平台，通过可治理的语义、可复用的场景插件、Agentic Workflow 和受控执行，将业务问题转化为可追溯的查询、分析、报告与看板。**

![首页官方业务场景](./docs/static/img/data-agent/zh-CN/home.png)

## DB-GPT 是什么？

DB-GPT 让团队在明确的业务与执行边界内委托 Agent 完成数据工作，核验结果依据，并复用有效的方法。

数据库结构不能完整解释指标；可执行的 SQL 仍可能因 JOIN 放大金额；长程多 Agent 任务需要明确阶段和复核点。DB-GPT 将这些问题纳入产品主线。

## 为什么选择 DB-GPT？

| 支柱 | 用途 | 指南 |
| --- | --- | --- |
| 可治理的语义 | 审核业务定义，发布 Agent 可读取和引用的指标版本 | [语义中心](./docs/i18n/zh-CN/docusaurus-plugin-content-docs/current/semantic-center/overview.md) |
| 场景插件 | 复用任务方法、Skills 与工具配置 | [插件中心](./docs/i18n/zh-CN/docusaurus-plugin-content-docs/current/plugins/overview.md) |
| Agentic Workflow | 明确阶段、Agent 责任、产物与 Gate | [Flow](./docs/i18n/zh-CN/docusaurus-plugin-content-docs/current/workflow/introduction.md) |
| 受控执行 | 配置资源、工具、审批和环境，检查执行证据 | [执行控制](./docs/i18n/zh-CN/docusaurus-plugin-content-docs/current/data-agent/controlled-execution.md) |

可信来自可核验定义与执行依据；控制取决于实际部署与工具配置，不保证每个生成计算自动正确。

## 你可以用 DB-GPT 做什么？

- **智能取数**：范围明确的问题、已执行 SQL、结果和可用指标引用。
- **智能分析**：业务调查、分析报告和经营看板。
- **SQL 优化专家**：带依据的诊断、改写和索引候选。
- **元数据与架构专家**：数据字典、物理 ER 和结构文档。
- **财报分析**：基于提供文件的财务分析与来源引用。

详见[场景案例](./docs/i18n/zh-CN/docusaurus-plugin-content-docs/current/use_cases.mdx)的输入、步骤与证据边界。

## 产品工作流

连接数据 → 准备已发布定义 → 选择插件 → 用 Flow 组织复杂阶段 → 检查确认与执行 → 核验成果。

Agent 在阶段内自主完成任务，Flow 显式组织依赖和交接，减少流程偏离、遗漏与不可校验结果。提示契约不是自动验证，异常可定位不等于断点恢复。

安装后完成[第一次数据任务](./docs/i18n/zh-CN/docusaurus-plugin-content-docs/current/data-agent/quickstart.md)。


## 快速开始

你可以通过一键安装脚本在几分钟内启动 DB-GPT（macOS / Linux）：

```bash
curl -fsSL https://raw.githubusercontent.com/eosphoros-ai/DB-GPT/main/scripts/install/install.sh | bash
```

也可以直接指定 profile 和 API Key：

```bash
curl -fsSL https://raw.githubusercontent.com/eosphoros-ai/DB-GPT/main/scripts/install/install.sh \
  | OPENAI_API_KEY=sk-xxx bash -s -- --profile openai
```

如果你想使用 Kimi 2.5（Moonshot API）：

```bash
curl -fsSL https://raw.githubusercontent.com/eosphoros-ai/DB-GPT/main/scripts/install/install.sh \
  | MOONSHOT_API_KEY=sk-xxx bash -s -- --profile kimi
```

如果你想使用 MiniMax（OpenAI 兼容接口）：

```bash
curl -fsSL https://raw.githubusercontent.com/eosphoros-ai/DB-GPT/main/scripts/install/install.sh \
  | MINIMAX_API_KEY=sk-xxx bash -s -- --profile minimax
```

如果你已经有本地 DB-GPT 仓库，也可以直接复用当前仓库，跳过 `~/.dbgpt/DB-GPT` 的重复 clone：

```bash
OPENAI_API_KEY=sk-xxx \
  bash scripts/install/install.sh --profile openai --repo-dir "$(pwd)" --yes
```

如果你想在当前仓库里直接测试 Kimi 2.5：

```bash
MOONSHOT_API_KEY=sk-xxx \
  bash scripts/install/install.sh --profile kimi --repo-dir "$(pwd)" --yes
```

如果你想在当前仓库里直接测试 MiniMax：

```bash
MINIMAX_API_KEY=sk-xxx \
  bash scripts/install/install.sh --profile minimax --repo-dir "$(pwd)" --yes
```

安装完成后，使用生成的 profile 配置启动服务：

```bash
cd ~/.dbgpt/DB-GPT && uv run dbgpt start webserver --profile <profile>
```

然后打开 [http://localhost:5670](http://localhost:5670)。

> **想先审阅安装脚本再执行？**
> ```bash
> curl -fsSL https://raw.githubusercontent.com/eosphoros-ai/DB-GPT/main/scripts/install/install.sh -o install.sh
> less install.sh
> bash install.sh --profile openai
> ```

### 通过 PyPI 安装

从 PyPI 安装 DB-GPT，一条命令即可启动，无需克隆源码仓库。

> **前置条件：** Python **3.10+**，推荐使用 [uv](https://docs.astral.sh/uv/getting-started/installation/) 包管理器，也支持 pip。

**1. 安装**

```bash
# 推荐使用 uv
uv pip install dbgpt-app

# 或使用 pip
pip install dbgpt-app
```

默认安装包含核心框架（CLI、FastAPI、Agent）、OpenAI 兼容 LLM 支持、DashScope / 通义支持、RAG 文档解析和 ChromaDB 向量存储。

**2. 启动**

```bash
dbgpt start
```

首次运行时，交互式向导会引导你选择 LLM 提供商并输入 API Key，配置完成后服务自动启动。

**3. 打开 Web 界面**

访问 [http://localhost:5670](http://localhost:5670) — 开始使用！🎉

## 核心能力

### Agentic 数据分析
- 任务规划
- 分步执行
- 工具调用
- 迭代式推理

### SQL + 代码执行
- 自然语言转 SQL
- Python 数据分析与处理
- 指标计算
- 图表生成

### 多数据源访问
- 关系型数据库
- CSV / Excel
- 文档
- 知识库
- 多源混合分析

### Skills 与 Agents
- 可复用 skills
- 领域分析工作流
- agent 编排
- 可定制执行流程

### 报告与决策支持
- 数据库画像报告
- 财报分析报告
- 可视化报告与 dashboard

## 愿景

我们的愿景是让数据工作可委托、可核验、可复用。团队提出业务问题后，能够知道 Agent 使用了哪些定义与资源，检查执行依据，并在关键决策处介入。

DB-GPT 通过可治理语义、场景插件、Agentic Workflow 和受控执行推进这一愿景，同时提供开放的开发能力供团队扩展。
